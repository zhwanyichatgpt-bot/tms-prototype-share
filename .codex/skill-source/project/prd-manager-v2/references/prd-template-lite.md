状态: 草稿 / 评审中 / 已确认
最后更新日期: YYYY-MM-DD
来源:
  - [来源路径]
---

## 精简原则

- 单角色功能可以省略角色表。
- 没有状态流转时可省略状态表，但要说明“不涉及状态变化”。
- 没有上下游联动时可写“不涉及”，不扩写假设内容。
- 字段很多时按页面或对象分组，不重复描述同一字段。
- 第 3、4、5、7 章是原型下游契约，不能只写概述。

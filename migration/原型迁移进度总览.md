## 六、迁移方法论（已验证，后续页面继续沿用）

1. **Skill-First**：原型迁移用 prototype-validator skill 加载规范
2. **结构清单优先**：复杂页先用 explore agent 摸清源结构，再重写
3. **mock-data.js 1:1 保留**：数据内容不动，只换载体（HTML 内联 → js 模块）
4. **Element Plus 组件映射**：el-table/el-form/el-drawer/el-dialog/el-select/el-date-picker/el-radio-group/el-checkbox-group/el-tag/el-empty/el-tabs/el-pagination/el-switch/el-input-number
5. **状态联动用 reactive store**：跨页面数据走 `src/shared/prototype-store.js`
6. **Verify-Before-Claim**：每页迁完跑 `npm run build`，构建通过才标记完成
7. **不迁标注**：源码中的 `<AnnotationOverlay>` 一律删除

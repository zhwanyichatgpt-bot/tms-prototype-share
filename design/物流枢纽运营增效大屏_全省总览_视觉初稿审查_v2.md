# 全省总览视觉初稿 V2 审查

## 1. 审查范围

- 审查对象：`物流枢纽运营增效大屏_全省总览_单屏视觉初稿_v2.png`
- 对照范围：PRD 中全省总览 D01—D11
- 用户目标：一张全省总览大屏，通过园区节点进入单园区二级屏

![审查截图](./物流枢纽运营增效大屏_全省总览_单屏视觉初稿_v2.png)

## 2. 总体结论

单屏信息架构和园区下钻入口方向正确，但当前稿不能直接进入原型实现。D01—D11 中仅 D04、D08 基本完整，8 项为部分满足，D11 不满足；累计指标、园区卡片字段、数据性质和效率排行存在明显缺失或错误。

## 3. 逐项符合度

| 编号 | 需求 | 结论 | 主要问题 |
|---|---|---|---|
| D01 | 全省园区分布地图 | 部分满足 | 有园区节点，但缺少接入状态及运行状态的清晰图例 |
| D02 | 全省核心指标 | 部分满足 | 缺累计出入园车次、累计吞吐量；综合吞吐量未展示实际/估算组成 |
| D03 | 园区摘要卡片 | 部分满足 | 缺园区类型、地址、主要货类、画像摘要、数据更新时间 |
| D04 | 园区选择与下钻 | 基本满足 | 地图卡片具备“进入园区”入口 |
| D05 | 仓库利用率趋势 | 部分满足 | 错误加入估算和预测曲线；缺日/周/月周期控制 |

## 4. 视觉与可用性问题

1. 中央地图层级清楚，园区下钻入口容易理解。
2. 右侧排行信息过密，远距离观看时园区名称及数值可读性不足。
3. “实际/估算/预测”被作为全局统一图例，造成仓储、车辆等不适用模块也出现估算或预测含义。
4. 地图卡片的“当前车辆”含义不明确，应改为“当前在园车辆”。
5. 实际、估算和预测主要依靠颜色区分，还需配合文字标签、线型或图标，避免仅靠颜色识别。
6. 当前日期、园区名称和数值均为视觉占位，不能作为业务确认内容。

## 5. V3 调整建议

1. 顶部补齐已接入园区、今日/累计出入园事件车次、今日/累计吞吐量、全省仓库利用率；当前预警移至预警模块或标题栏角标。
2. 吞吐量卡片同时显示实际和估算组成，只有全省总览允许显示“综合（含估算）”。
3. 左侧三个趋势分别采用各自正确图例，并增加日/周/月切换。
4. 地图节点增加“园区接入状态＋运行状态”图例。
5. 园区摘要卡片补齐园区类型、地址、当前在园车辆、今日吞吐量、主要货类、画像摘要、更新时间和数据性质。
6. 右侧排行调整为仓储利用率、吞吐量、车辆出入、平均装卸时长、单位面积吞吐量五类，避免综合效率评分。
7. 保留“进入园区”作为唯一二级屏入口，首页不展示 D12—D24 的园区专题指标。

## 6. 证据边界

本次仅审查静态设计图片，无法验证鼠标指向、园区下钻、加载、空数据、过期和返回全省等交互状态；这些需在设计稿确认后通过可交互原型验证。

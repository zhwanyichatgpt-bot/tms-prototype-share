# 一单制凭证客户展示原则

## 1. 文档定位

本文用于沉淀一单制运输凭证在客户侧展示时的长期业务原则，作为后续凭证页、轨迹页、PDF 下载、打印和客户查询相关 PRD 的统一依据。

本文不描述具体页面布局、按钮、颜色、下载交互和字段校验。

## 2. 对象定位

1. 联运计划是内部编排与执行组织对象。
2. 一单制运输凭证是联运计划生效后生成的对客正式凭证对象。
3. 扫码轨迹页是凭证二维码对应的动态查询对象，不等于完整凭证重复页。
4. 用户提供的图片、样张或行业材料只能作为辅助理解材料，不直接替代正式业务规则。

## 3. 客户侧主体原则

1. 客户侧统一服务主体为“多式联运经营人”。
2. “全程责任主体”本期不单独设字段，客户认知由多式联运经营人统一承接。
3. “统一结算主体”表述不使用，统一改为“结算方”。
4. 结算方默认指向货主 / 托运企业。
5. 不对客户默认展示实际分段承运商。

## 4. 凭证生成与有效性原则

1. 联运计划草稿状态不生成正式凭证号和二维码。
2. 联运计划生效后，系统生成正式凭证号、签发日期和二维码。
3. 凭证有效性跟随联运计划状态变化。
4. 联运计划作废或失效后，凭证同步失效或不可查询。
5. 是否需要独立凭证作废流程，由后续凭证管理功能单独确认。

## 5. 客户侧信息展示边界

1. 凭证页承接客户留档、在线查看、下载和打印等对客场景。
2. 凭证页应重点展示凭证识别信息、客户关系、货物摘要、全程路线、分段运输摘要和费用摘要。
3. 凭证说明区需明确“最新轨迹以二维码查询结果为准”。
4. 运输状态可以动态展示，但不要求对客展示凭证版本号。
5. 动态字段未回传时，不展示“待回传”等系统过程提示文案。

## 6. 分段与区段展示原则

1. 凭证页可以展示分段运输明细和区段单证号。
2. 区段单证号允许对客展示，但不需要在所有页面层级默认高频暴露。
3. 客户如需查看区段单证号，应在分段详情或对应明细中查看。
4. 轨迹页不应重复完整凭证正文，应以当前运输进展和动态查询为主。

## 7. 费用展示边界

1. 凭证费用区只展示客户侧摘要信息。
2. 不展示详细计价过程、分段成本、内部执行成本、税率拆解和对账 / 开票细节。
3. 费用字段颗粒度应以客户侧理解为主，不与正式结算单职责混淆。
4. 后续若费用摘要字段继续细化，应与费用与结算相关规则保持一致。

## 8. 字段来源原则

一单制主题中的关键字段，正式 PRD 应按以下维度表达：

- 取值来源
- 生成或取值时机
- 取值规则
- 空值或未回传时的展示规则

不能只写“展示字段是什么”，必须写清字段来源对象或能力层级。

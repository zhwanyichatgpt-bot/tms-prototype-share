# 计费条件与计费依据口径

## 1. 文档定位

本文用于统一费用相关字段的基础命名和业务含义，避免在报价、运输方案、运输计划和运费结算中出现“计费维度、结算口径、报价口径”等混用问题。

本文只定义跨模块口径，不替代具体功能 PRD 中的字段规则、必填规则和计算规则。

## 2. 标准名称

### 2.1 计费条件

**定义：** 计费条件用于表达费用按照什么业务对象、数量条件或计量方式进行计算。

**常见取值：**

- 按重量
- 按体积
- 按数量
- 按集装箱
- 按车
- 按里程

**适用范围：**

- 承运商报价
- 运输通道
- 运输方案
- 公路运输计划
- 多式联运计划
- 运费结算

**命名要求：**

- 新文档统一使用“计费条件”。
- 历史文档中的“计费维度”如语义一致，应逐步调整为“计费条件”。

### 2.2 计费依据

**定义：** 计费依据用于表达费用取值以哪个业务环节或确认口径为准。

**常见取值：**

- 按装货口径
- 按卸货口径

**适用范围：**

- 散杂货报价
- 散杂货运输计划
- 散杂货运费结算

**命名要求：**

- 新文档统一使用“计费依据”。
- 历史文档中的“结算口径”“报价口径”如果表达装货/卸货取值口径，应逐步调整为“计费依据”。

## 3. 两者区别

| 字段 | 解决的问题 | 示例 |
|---|---|---|
| 计费条件 | 按什么条件算钱 | 按重量、按体积、按数量、按集装箱 |
| 计费依据 | 取哪个环节的数据作为计算依据 | 按装货口径、按卸货口径 |

示例：

```text
计费条件 = 按重量
计费依据 = 按卸货口径
含义：费用按照重量计费，重量取卸货确认后的重量。
```

## 4. 使用边界

1. 集装箱场景通常固定为“计费条件 = 按集装箱”，一般不需要选择计费依据。
2. 散杂货场景通常需要同时明确计费条件和计费依据。
3. 运输单价应与计费条件匹配，例如按重量时单价单位为“元/吨”。
4. 具体小数位、金额计算、为空校验、是否允许 0 等规则，放在对应 PRD 字段说明中。

## 5. 历史口径处理

| 历史名称 | 新口径 | 处理方式 |
|---|---|---|
| 计费维度 | 计费条件 | 后续 PRD 和原型说明统一替换。 |
| 结算口径 | 计费依据 | 当语义为装货/卸货取值口径时替换。 |
| 报价口径 | 计费依据 | 不建议作为正式字段名。 |

## 6. 后续维护规则

1. 若新增计费条件，应先确认是否适用于多个模块。
2. 若只属于某个功能的临时字段，不进入本文。
3. 结算模块细化后，如出现新的费用确认口径，应回到本文补充。

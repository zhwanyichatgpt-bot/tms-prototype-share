# 运输通道与运输方案功能分析结论 v2

> 说明：本文件中的已确认结论已吸收进入 `08-方案设计/运输通道管理_运输通道与运输方案管理_PRD_v2.md`，当前文件保留为讨论收口依据，不再作为主PRD使用。

## 1. 本版相对 v1 的关键修正
1. 运输通道页的路径配置由“路径详情大表单”收敛为“路径列表 + 结构搭建”，重点通过新增路段 / 新增运输节点 / 新增作业节点完成配置。
2. 运输通道页的展示信息由自由文本收敛为轻量结构化字段：参考价、参考时效、通道说明。
3. 运输通道页中的“运输类型（散货 / 集装箱）”不再作为主字段，运输方式保留在路径/路段上。
4. 运输方案页中“运输类型”不再作为方案头部统一字段，而改为在绑定主路径的路段上维护。
5. 运输方案页中的路段运输方式来自来源通道路径，只读带入，不允许在方案中修改。
6. 运输方案页中的上门 / 末端服务范围改为用户自行配置，采用省 / 市 / 区多选级联，不使用系统预置标签。
7. 增值服务改为字典值多选，并支持新增自定义服务项。
8. 运输方案页中的标准价格结构与承运商报价页、联运计划费用规则对齐，不再自造一套费用口径。
9. 运输方案页中的“其他费用”口径与报价页保持一致，改为“标准其他费用”，支持结构化列表而不是纯标签模板。
10. 路段候选承运商改为“当前页展示已选结果 + 弹窗/抽屉选择过程”，不再页内展开候选池。

## 2. 对象定义

### 2.1 运输通道
定位：
- 经营侧运输能力资产
- 相对稳定、可经营、可复用
- 可发布到大厅

核心承载：
- 集货点 / 目的地
- 多条路径
- 节点结构 / 作业节点
- 每段运输方式
- 服务能力标签
- 通道展示信息（参考价、参考时效、通道说明）

不承载：
- 面向货主的正式报价
- 标准价格结构
- 候选承运商
- 实际执行承运商
- 方案级服务范围

### 2.2 运输方案
定位：
- 企业内部标准复用经营方案
- 后续报价母版

核心承载：
- 来源运输通道
- 绑定主路径
- 主路径各路段运输类型（散货 / 集装箱）
- 标准服务组合
- 标准价格结构
- 标准其他费用
- 常规时效范围与时效说明
- 路段候选承运商

不承载：
- 货主正式报价结果
- 实际执行承运商
- 调度信息

### 2.3 报价
定位：
- 面向具体货主需求的正式商务结果

说明：
- 报价引用方案内容生成，不与方案保持实时绑定
- 货主确认报价后，报价冻结，再进入联运计划

### 2.4 联运计划
定位：
- 承接执行编排
- 进入调度中心确定实际执行资源

## 3. 通道页与方案页的职责边界

### 3.1 运输通道页表达“怎么走”
- 起点 / 终点
- 路径列表
- 路段
- 节点 / 作业节点
- 每段运输方式
- 通道能力标签
- 通道展示摘要

### 3.2 运输方案页表达“怎么卖”
- 绑定哪条主路径
- 主路径各路段按什么运输组织形态经营
- 标准服务组合
- 标准价格结构
- 标准其他费用
- 常规时效范围
- 候选承运商

## 4. 路径规则
- 路径属于运输通道层，不下沉到运输方案层。
- 一条运输通道下可维护多条路径。
- 路径用于表达不同走法、不同运输方式组合、不同途经点。
- 路径配置以结构搭建为主：新增路段、新增运输节点、新增作业节点。
- 通道页不再维护路径级参考价、路径级参考时效。
- 若需要新路径，应先补到运输通道，再基于该路径创建运输方案。
- 集货点、目的地是运输通道级边界字段，用于定义该通道整体从哪到哪。
- 路段起点、终点是路径明细字段，用于表达该路径具体怎么走。
- 每条路径的首段起点应与通道集货点一致。
- 每条路径的末段终点应与通道目的地一致。
- 相邻路段必须首尾衔接，前一段终点应等于后一段起点。
- 新增首段时，起点默认带出集货点；若当前仅一段，终点默认带出目的地。
- 新增下一段时，下一段起点默认承接上一段终点。
- 若用户将首段终点从目的地改为中间点，则视为从单段路径调整为多段路径，应继续补齐后续路段直至目的地。
- 上述规则同时适用于单一运输方式与多式联运场景。

## 5. 运输方式与运输类型规则
- 运输方式维护在通道路径/路段上，例如公路 / 水路 / 铁路。
- 运输方案中，主路径路段的运输方式来自来源通道，只读带入，不允许修改。
- 运输类型（散货 / 集装箱）在运输方案绑定的主路径路段上配置，不作为方案头部统一字段。
- 这样可支持散改集、集改散等多式联运场景。

## 6. 服务组合规则
- 通道层仅表达能力标签：是否支持上门、末端、通关、增值服务。
- 方案层表达标准服务组合：是否包含上门、末端、通关、增值服务。
- 勾选“包含上门 / 包含末端”后，应配置服务范围。
- 服务范围由用户自行配置，采用省 / 市 / 区多选级联，不使用系统预置固定标签。
- 增值服务项采用字典值多选，并支持新增自定义服务项。
- 方案层的货种 / 箱型应受来源通道能力约束。

## 7. 价格与费用规则
- 运输方案页中的标准价格结构应对齐承运商报价页与联运计划费用规则。
- 费用组织方式统一为：整段 / 分段。
- 整段模式下，按整体维护标准价格结构。
- 分段模式下，按主路径各路段分别维护价格结构，且应覆盖全部路段。
- 若某路段运输类型为集装箱，则该段按集装箱计费，并通过箱型价格明细表达。
- 若某路段运输类型为散货，则该段可按重量 / 体积 / 数量表达。
- “统一展示口径”字段已删除，不再单独维护。
- “常见费用项模板”口径调整为“标准其他费用”，并与报价页其他费用结构保持一致。

## 8. 承运商规则
### 8.1 运输方案层
维护的是可用承运商：
- 候选承运商
- 已有合作承运商 / 平台推荐承运商
- 按路段维度维护
- 页面主视图只展示已选结果
- 新增承运商通过弹窗/抽屉选择

### 8.2 联运计划层
维护的是实际执行承运商：
- 进入调度中心后确定
- 可能调度给第三方承运商

### 8.3 货主侧展示
- 报价不展示下游承运商
- 报价不展示内部成本拆分

## 9. 大厅展示结论
- 大厅主展示对象是运输通道。
- 大厅主动作是发起询价，不是直接标准化成交下单。
- 大厅展示口径以通道稳定信息为主：起点 / 终点、运输方式、参考价、参考时效、服务能力标签、是否多路径 / 是否联运。
- 不直接展示运输方案明细。

## 10. 状态结论
### 10.1 通道本体状态
- 草稿
- 启用
- 停用

### 10.2 发布状态
- 未发布
- 已发布
- 已下架

### 10.3 状态约束
- 草稿只能是未发布。
- 只有启用状态的通道才能发布。
- 停用通道不能继续已发布；如已发布，应自动下架。
- 停用通道不可新增运输方案。

## 11. 页面功能拆分结论
### 11.1 运输通道管理
定位：通道资产管理入口
核心动作：查看、编辑、发布/下架、停用、查看方案、新增方案
补充确认：
- “查看方案”采用抽屉承载方案列表核心内容

### 11.2 新增运输通道
定位：新增运输能力资产
核心内容：基础信息、路径配置、服务能力、展示信息
补充确认：
- 业务方向保留、单选、非必填
- 支持箱型范围按需显示、手动开启
- 路径区采用“轻量路径卡片 + 当前路径编辑区”
- 展示信息采用结构化参考价、结构化参考时效与通道说明

### 11.3 运输方案管理
定位：内部标准复用方案管理入口
核心动作：查看、编辑、复制、停用、查看来源通道
补充确认：
- 来源通道能力约束采用“展示但置灰禁用 + 提示”的方式表达

### 11.4 新增运输方案
定位：基于来源通道与主路径沉淀标准方案母版
核心内容：来源信息、标准服务组合、标准价格结构、标准时效、路段候选承运商
补充确认：
- 来源信息区仅保留轻量摘要字段
- 自定义增值服务项一期仅当前方案生效
- 候选承运商弹窗支持多选、搜索与统一确认添加
- 标准其他费用一期不做企业级模板中心
- 整段模式给默认值，分段模式按路段运输类型联动

# 公路结算 AI 任务卡

## 一、任务概述

计划创建企业（无车承运人）在结算环节存在三类高频操作：
1. 手动筛选运单、分组、填写规则，创建结算单，步骤多、易漏项
2. 收到货主对账表后人工逐条核对，耗时且容易遗漏
3. 按不同货主要求手动整理导出表格，重复劳动

本任务卡定义结算 AI 能力，接入 AI 工作台（卡托台），通过对话驱动完成**创建→对账→导出**全链路，AI 负责数据拉取、规则带入、差异分析和格式生成，判断和确认始终由用户完成。

---

## 二、适用角色与入口

| 项目 | 说明 |
|---|---|
| 使用角色 | 计划创建企业的结算人员 |
| 入口 | AI 工作台 → AI 助手对话界面 |
| 触发方式 | 用户对话主动发起，AI 识别结算相关意图 |
| 右侧联动页 | 命中结算意图后，右侧打开对应结算单创建页或查看页 |

## 三、能力模块

### 模块一：主动创建结算单

**触发场景：** 用户说"给货主A创建10月的结算单"、"帮我把上月未结算的都结一下"等

**AI 做的事：**
1. 识别结算方（货主）、时间范围、结算方向（上游/下游）
2. 拉取该货主在该时间范围内所有未结算运单
3. 按计划（货源计划）分组
4. 带入每个计划对应的计费规则（计费条件、计费依据、单价）
5. 计算每组未结算量和预估金额
6. 右侧打开结算单创建页，预填所有内容
7. 左侧输出汇总卡片：共涉及X个计划、X条运单、预计金额X元，请确认

**用户做的事：**
- 核查预填内容是否正确（数量、单价）
- 如有调整，在右侧页面手动修改
- 确认无误后提交

**AI 不做的事：**
- 不自动提交，提交必须由用户发起
- 不跨货主合并，一次对话针对一个结算方
- 不修改计费规则（只读取，不覆盖）

---

### 模块二：对账比对

**触发场景：** 用户上传货主对账表 Excel，或说"货主发来了对账表，帮我核对"

**AI 做的事：**

**Step 1 解析**
- 解析上传的 Excel，提取：运单号、货品、重量/数量、单价、金额等
- 识别表头变体，自动映射到系统标准字段
- 输出字段映射预览，供用户确认

**Step 2 匹配**
- 将对账表条目与系统结算单运单逐条匹配
- 匹配依据：运单号（优先）、车牌+日期+路线（次选）
- 输出三类结果：已匹配 / 系统有货主无 / 货主有系统无

**Step 3 差异分析与建议**
对已匹配但数值不一致的条目，AI：
- 计算差异量和差异率
- 调取该运单的装货/卸货凭证（磅单）
- 结合凭证分析差异可能原因
- 给出有依据的建议，不替用户做决定

建议措辞原则：
- 有凭证支持 → 说明凭证数值，指出与哪方一致，建议以凭证为准
- 差异在合理损耗范围内 → 说明属于正常范围，建议以系统为准
- 差异较大无凭证 → 说明差异情况，提示需核实合同或联系货主
- 单价差异 → 提示单价不一致，建议核对合同约定

**Step 4 结果卡片**
- 对账汇总：匹配总数、无差异数、有差异数、未匹配数
- 差异清单：每条展示系统值、货主值、凭证值（如有）、AI建议
- 每条可操作：以系统为准 / 以货主为准 / 暂搁置
- 用户逐项确认后汇总，一键提交结算单更新

**结算单修改规则：**

| 用户选择 | 修改内容 | 金额处理 |
|---|---|---|
| 以系统为准 | 不改，记录货主差异备注 | 不变 |
| 以货主为准 | 修改结算单对应字段 | 自动按新值重算 |
| 暂搁置 | 不改，标注"待确认" | 不变 |

---

### 模块三：导出结算表格

**触发场景：** 用户说"帮我生成发给货主A的结算表"、"按货主要求的格式导出"

**AI 做的事：**
1. 识别目标结算单和导出对象（货主/承运商）
2. 询问或识别对方要求的表格格式（如有历史记录，直接复用）
3. 按指定格式生成 Excel 表格
4. 直接提供下载，用户线下发送

**价值：** 省掉手动整理格式的重复工作，不同货主格式不同也能按需生成。

**AI 不做的事：**
- 不直接发送给货主（线下发送仍由用户完成）
- 不修改结算单数据，只做格式转换输出

## 四、整体交互形态

```
AI 工作台
├─ 左侧：对话界面
│  ├─ 用户发起（文字指令 / 上传文件）
│  ├─ AI 返回汇总卡片（创建结果 / 对账结果 / 导出结果）
│  └─ 用户在卡片上操作（确认 / 选择处理方式 / 下载）
└─ 右侧：结算单创建页 / 查看页
   └─ 命中结算意图后联动打开，供用户参照和修改
```

三个模块全部走左聊天+右联动页的交互形态，不另开独立工具页。

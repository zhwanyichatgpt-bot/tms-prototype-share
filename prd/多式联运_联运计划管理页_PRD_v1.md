# 联运计划管理页 PRD

## 0. 一句话说明

联运计划管理页是货代查看、筛选和处理联运计划的统一工作台，承接创建页新增回写，并通过状态页签、主列表、展开区和操作列完成联运计划及其子计划的查看与状态处理。

## 1. 背景与范围

### 1.1 需求背景
- 联运计划管理页是货代查看、筛选和处理联运计划的统一工作台。
- 管理页原型已经完成结构收口，新增入口、状态页签、主列表、展开区和状态操作联动均已可演示。
- 旧文档按页面区域罗列，核心链路、对象关系、状态联动和字段口径不够集中，需要按新版 PRD 模板重构。

### 1.2 需求目标
- 明确联运计划管理页的页面结构、字段口径和状态操作边界。
- 明确管理页与创建页之间的新增 / 返回回写链路。
- 明确主计划与子计划在暂停、开启、作废、重新发布下的联动规则。

### 1.3 适用范围
- 适用模块：多式联运。
- 适用页面：联运计划管理页。
- 本期覆盖：筛选区、状态页签、主列表、展开区、操作列、状态联动、与创建页联动。
- 适用角色：货代。

### 1.4 非本期范围
- 真实详情页。
- 真实编辑页。
- 结算结果页。
- 子计划管理页。
- 调整能力。
- 待审批状态。

### 1.5 原型状态
- 当前原型目录：`AI输出/原型验证/联运计划/管理页/current/`
- 当前原型已完成：新增联运计划入口、筛选区、状态页签、主列表、展开区、按状态显隐的操作列、暂停 / 开启 / 作废 / 重新发布联动。
- 当前原型已与创建联运计划页打通：保存草稿 / 生效后可返回管理页并回写记录。
- 当前仍未稳定的内容已转入待确认事项，不在 PRD 中写成既定事实。

## 2. 核心链路

```text
货代进入联运计划管理页
    ↓
通过筛选区和状态页签定位目标联运计划
    ↓
在主列表查看联运计划级摘要
    ↓
展开计划行查看子计划明细
    ↓
按当前状态执行详情、编辑、删除、暂停、开启、作废、重新发布等动作
    ↓
状态操作后同步刷新主计划和未完成子计划状态
    ↓
需要新增时点击新增联运计划，进入创建页
    ↓
创建页保存草稿或生效后返回管理页并回写记录
```

**关键决策点：**
- 主列表只展示联运计划级摘要，子计划明细放在展开区。
- 不同状态下操作列动态显隐，不提供统一全量操作。
- 暂停、开启、作废、重新发布需要联动未完成子计划状态。
- 已完成子计划在暂停 / 作废链路下保持已完成。
- 详情、编辑、结算结果、子计划管理等后续页面当前只做占位承接。

## 3. 核心概念与对象关系

### 3.1 核心对象
| 对象 | 说明 |
|---|---|
| 联运计划 | 管理页主列表中的计划级对象 |
| 子计划 | 联运计划下的分段执行计划，在展开区查看 |
| 筛选条件 | 用于定位列表数据的查询条件 |
| 状态页签 | 按联运计划主状态切换展示范围 |
| 操作列 | 根据联运计划状态动态展示可执行动作 |
| 创建页回写记录 | 从创建联运计划页保存或生效后回写到管理页的记录 |

### 3.2 对象关系
- 一个联运计划可包含多个子计划。
- 管理页主列表展示联运计划摘要，展开区展示该计划下的子计划明细。
- 创建页保存草稿或生效后，向管理页回写新增 / 更新记录。
- 主计划状态操作会影响未完成子计划状态，但已完成子计划保持不变。

### 3.3 状态流转
| 当前状态 | 触发动作 | 下一状态 | 子计划联动 | 说明 |
|---|---|---|---|---|
| 草稿 | 删除 | 移除记录 | 不涉及 | 删除前需确认 |
| 草稿 | 生效后回写 | 待执行 | 草稿子计划可同步待执行 | 由创建页生效触发 |
| 待执行 | 暂停 | 已暂停 | 未完成子计划同步已暂停 | 已完成子计划不变 |
| 执行中 | 暂停 | 已暂停 | 未完成子计划同步已暂停 | 已完成子计划不变 |
| 已暂停 | 开启 | 待执行 / 执行中 | 子计划恢复暂停前状态 | 若存在执行中子计划则主计划恢复执行中 |
| 待执行 | 作废 | 已作废 | 未完成子计划同步已作废 | 已完成子计划不变 |
| 已暂停 | 作废 | 已作废 | 未完成子计划同步已作废 | 已完成子计划不变 |
| 已作废 | 重新发布 | 草稿 | 子计划同步恢复草稿 | 重新发布后须再次"生效"才能回到待执行，路径与新建一致：草稿 →（生效）→ 待执行 |
| 已完成 | 查看详情 | 已完成 | 不联动 | 不提供结构性操作 |

## 4. 核心规则

1. 管理页主列表只承接联运计划级摘要，子计划细节统一放在展开区。
2. 状态页签当前包括全部、草稿、待执行、执行中、已暂停、已作废、已完成。
3. 暂停、开启、作废、重新发布操作必须同步联动未完成子计划状态。
4. 已完成子计划在暂停、作废链路下保持已完成不变。
5. 待执行状态只允许编辑非结构性字段（备注、装卸时间、联系人、联系电话等），不允许调整运输方式、运输类型、装货点、卸货点等结构性字段，不支持调整能力。
6. 管理页需承接来自创建页的本地回写记录，形成新增 → 管理的演示闭环。
7. 详情、编辑、结算结果、子计划管理等后续页面当前只做入口占位，不在本 PRD 展开。

## 5. 功能详细说明

### 5.1 页面结构

#### 5.1.1 功能说明
- 功能目的：提供联运计划管理页的整体信息架构。
- 使用角色：货代。
- 触发入口：进入联运计划管理菜单。

#### 5.1.2 页面与交互逻辑
- 顶部为筛选区。
- 筛选区下方为状态页签。
- 主列表仅展示联运计划级摘要。
- 子计划明细统一放在展开区查看，不在主列表重复铺陈。
- 页面顶部提供“新增联运计划”入口，跳转到创建联运计划页。

### 5.2 筛选区

#### 5.2.1 功能说明
- 功能目的：帮助用户按关键条件定位联运计划。
- 使用角色：货代。

#### 5.2.2 页面与交互逻辑
- 当前筛选项保留：联运计划名称 / 编号、关联托运单、托运企业、创建人、创建时间区间。
- 创建时间区间已纳入筛选（主列表 7.3 中"创建时间"为固定展示字段，筛选需与展示项对称）；如原型尚未实现，应在正式收口时补齐。
- 点击“查询”按当前条件过滤当前页签内数据。
- 点击“重置”清空筛选条件并恢复当前页签默认列表。
- 切换状态页签时，当前原型保留筛选条件；正式是否维持该策略待确认。

### 5.3 状态页签

#### 5.3.1 功能说明
- 功能目的：按联运计划主状态切换列表展示范围。

#### 5.3.2 页面与交互逻辑
- 当前主状态包括：全部、草稿、待执行、执行中、已暂停、已作废、已完成。
- 页签用于切换主列表展示范围。
- 不在本期引入“待审批”等额外状态。

### 5.4 主列表与展开区

#### 5.4.1 功能说明
- 功能目的：主列表展示计划级摘要，展开区展示子计划明细。

#### 5.4.2 页面与交互逻辑
- 主列表字段收口为：联运计划信息、联运计划状态、托运企业、关联托运单、货品摘要、结算方式、创建人、创建时间、备注、操作。
- 主列表只承接计划级摘要信息，不重复展示子计划与路段明细。
- 动态从创建页回写的记录应合并到当前列表数据中。
- 展开区用于查看该联运计划下的子计划明细。
- 展开区当前展示字段包括：子计划名称 / 编号、状态、运输方式、装货点 → 卸货点、路段货量摘要、路段计划时间。
- 当前原型仍采用嵌套表格 / 子表展示形式；正式定稿形式待确认。

### 5.5 操作列

#### 5.5.1 功能说明
- 功能目的：按联运计划状态展示可执行动作。

#### 5.5.2 动作规则
| 状态 | 展示动作 | 说明 |
|---|---|---|
| 草稿 | 详情、编辑、删除 | 删除前需确认 |
| 待执行 | 详情、编辑、暂停、作废 | 编辑仅允许非结构性字段 |
| 执行中 | 详情、暂停 | 不提供编辑 |
| 已暂停 | 详情、开启、作废 | 开启后恢复暂停前状态 |
| 已作废 | 详情、重新发布 | 当前恢复为草稿 |
| 已完成 | 详情 | 不提供结构性操作 |

### 5.6 状态操作与联动

#### 5.6.1 功能说明
- 功能目的：定义主计划状态操作与子计划状态之间的联动规则。

#### 5.6.2 页面与交互逻辑
- 重新发布已作废计划时，主计划与子计划恢复为草稿；恢复草稿后须再次"生效"才能回到待执行（与新建草稿→生效→待执行路径一致），不存在"作废→直接待执行"的跳转。是否强制重新生效当前为强制：必须再次生效才能继续执行链路。
- 删除草稿时，确认后从列表中移除。
- 暂停待执行 / 执行中计划时，主计划状态改为已暂停，未完成子计划同步已暂停，已完成子计划保持已完成。
- 开启已暂停计划时，子计划恢复到暂停前原状态；若存在执行中的子计划，主计划恢复为执行中，否则恢复为待执行。
- 作废草稿 / 待执行 / 已暂停计划时，主计划状态改为已作废，未完成子计划同步已作废，已完成子计划保持已完成。
- 重新发布已作废计划时，当前原型口径为主计划恢复为草稿，子计划状态同步恢复为草稿。
- 状态操作执行后，展开区子计划状态应实时刷新，无需手动刷新页面。

### 5.7 页面关系与承接

#### 5.7.1 功能说明
- 功能目的：定义管理页与创建页、后续占位页面之间的页面承接关系。

#### 5.7.2 页面与交互逻辑
- 点击“新增联运计划”进入创建联运计划页。
- 创建页保存草稿 / 生效后返回管理页，并回写新增 / 更新记录。
- 详情、编辑、结算结果、子计划管理等后续页面当前只做占位承接，不在本轮真实展开。

## 6. 上下游联动

### 6.1 上游
- 创建联运计划页保存草稿或生效后，回写管理页列表记录。

### 6.2 下游
- 管理页的详情、编辑、结算结果、子计划管理入口承接后续页面。
- 状态操作会影响主计划和子计划状态展示。

### 6.3 边界说明
- 本 PRD 只定义管理页展示、筛选、展开和状态操作。
- 真实详情页、编辑页、结算结果页、子计划管理页不在本 PRD 展开。
- 重新发布后是否必须重新生效，作为待确认事项继续收口。

## 7. 字段说明

### 7.1 筛选区
- **联运计划名称 / 编号**：类型：文本框；是否必填：否；联动影响：按计划名称或编号模糊查询。
- **关联托运单**：类型：文本框 / 选择字段；是否必填：否；联动影响：筛选关联指定托运单的计划。
- **托运企业**：类型：文本框 / 选择字段；是否必填：否；联动影响：筛选指定托运企业的计划。
- **创建人**：类型：文本框 / 选择字段；是否必填：否；联动影响：筛选指定创建人的计划。

### 7.2 状态页签
- **状态页签**：类型：页签；可选值：全部、草稿、待执行、执行中、已暂停、已作废、已完成；联动影响：切换主列表展示范围。

### 7.3 主列表
- **联运计划信息**：类型：摘要字段；展示内容：联运计划名称 / 编号。
- **联运计划状态**：类型：状态标签；展示条件：列表固定展示。
- **托运企业**：类型：文本；展示条件：列表固定展示。
- **关联托运单**：类型：文本 / 链接；展示条件：有值时展示。
- **货品摘要**：类型：文本；展示内容：货品名称、数量 / 重量 / 体积摘要。
- **结算方式**：类型：文本 / 标签；展示内容：整票结算 / 分段结算；取值来源：联运计划费用信息区的"结算组织方式"字段（创建联运计划页配置）。
- **创建人**：类型：文本；展示条件：列表固定展示。
- **创建时间**：类型：日期时间；展示条件：列表固定展示。
- **备注**：类型：文本；展示条件：有值时展示。
- **操作**：类型：按钮组；展示条件：按状态动态展示。

### 7.4 展开区
- **子计划名称 / 编号**：类型：文本；展示条件：展开后展示。
- **子计划状态**：类型：状态标签；展示条件：展开后展示。
- **运输方式**：类型：标签 / 文本；展示条件：展开后展示。
- **装货点 → 卸货点**：类型：文本；展示条件：展开后展示。
- **路段货量摘要**：类型：文本；展示条件：展开后展示。
- **子计划计划时间**：类型：日期时间；展示条件：展开后展示；口径：子计划（路段）级计划执行时间，原"路段计划时间"字段名的"路段计划"是子计划历史名称（已禁用），统一为子计划。

# 货源询价管理货主端 PRD

> 说明：本文档只描述货主端“货源询价”的页面、字段、操作和校验规则。全局对象关系、三端状态联动和跨端规则见总览 PRD。

## 0. 一句话说明

货主通过“货源询价”发布长协或零星货源询价，一张货源询价可包含多条路线，并在详情中查看路线处理进度、按路线确认无车承运人提交的报价、基于已确认路线生成指定托运单。

## 1. 背景与范围

### 1.1 需求背景
- 广林项目货主需要一次发布多条路线的货源询价。
- 当前主对象已从“长协询价批次”调整为“货源询价”，通过询价类型区分长协货源询价与零星货源询价。
- 货主侧需要完整承载“列表查看 → 新增发布 → 详情确认 → 生成指定托运单”的操作链路。

### 1.2 需求目标
- 支持货主查看自己发布的全部货源询价。
- 支持货主新增长协货源询价或零星货源询价，并维护多条路线。
- 支持货主查看无车承运人处理进度和已提交报价。
- 支持货主按路线确认报价并生成指定托运单。

### 1.3 适用范围
- 货主端“货源询价”应用。
- 货源询价列表页。
- 新增货源询价页。
- 货源询价详情页。
- 路线确认与指定托运单生成入口。

### 1.4 非本期范围
- 货主侧多家无车承运人公开大厅。
- 长协货源询价与零星货源询价差异字段。
- 指定托运单生成后的完整履约执行流程。

### 1.5 原型状态
- 旧版原型已有货主批次创建、货主确认、托运单生成等 Tab 视图。
- 后续原型需重构为货主端“货源询价列表页 / 新增货源询价页 / 货源询价详情页”。

## 2. 核心链路
1. 货主进入“货源询价”列表页。
2. 货主点击“新增货源询价”。
3. 货主选择询价类型：长协货源询价或零星货源询价。
4. 货主填写货源询价基本信息。
5. 货主手工新增或模板导入路线明细。
6. 系统执行必填、配载方式、货量、单位和重复路线校验。
7. 货主保存草稿或发布货源询价。
8. 发布成功后，货源询价进入无车承运人询价管理处理。
9. 无车承运人提交对货主报价后，货主在详情页按路线确认。
10. 已确认路线生成指定托运单。

### 2.1 关键决策点
- 询价类型只是主信息字段，本期不影响页面字段显隐。
- 路线是确认和生成指定托运单的最小单元。
- 货主可部分确认路线，未确认路线继续保留对应处理状态。
- 一条路线最多生成一张指定托运单。

## 3. 核心概念与对象关系

### 3.1 当前 PRD 管理对象
| 对象 | 说明 |
|---|---|
| 货源询价 | 货主发布的一次询价任务 |
| 路线明细 | 货源询价下的路线需求 |
| 对货主报价 | 无车承运人选择承运商报价后提交给货主的价格 |
| 指定托运单 | 货主确认路线后生成的履约单据 |

### 3.2 对象关系
- 1 张货源询价包含 N 条路线明细。
- 1 张货源询价仅对应 1 个询价对象（无车承运人）。
- 1 条路线明细最多有 1 个当前有效对货主报价。
- 1 条已确认路线最多生成 1 张指定托运单。

### 3.3 状态流转
#### 货源询价状态
草稿 → 待承接 → 待报价 → 待确认 → 已完成 / 已拒绝 / 已取消

- 已完成的触发条件：货源询价下全部有效路线均到达终态（已生成托运单 或 已取消）。存在长期"待货主确认"或"已驳回"未回流的路线时，主单不进入已完成，仍保留在待确认，由货主继续处理或主动取消该路线。
- 已拒绝：由询价对象（无车承运人）整体拒绝承接触发。

#### 路线状态
- 待处理 → 报价中 → 待货主确认 → 已确认 → 已生成托运单
- 待货主确认 → 已驳回（货主驳回）→ 报价中（无车承运人重新提交报价后回流）
- 任一可取消态 → 已取消（随主单取消或单独取消，单独取消能力本期未开放，预留）

异常分支：待货主确认 → 已驳回；已驳回不是终态，无车承运人重新提交后回到报价中→待货主确认。

## 4. 核心规则
1. 货源询价必须选择询价类型，当前支持长协货源询价和零星货源询价。
2. 本期长协货源询价与零星货源询价字段一致。
3. 一张货源询价只能选择 1 个询价对象（无车承运人），不支持同一张询价单同时发给多个对象。
4. 货源询价至少包含 1 条路线才允许发布。
5. 同一货主、同一货源询价内，重复路线不允许发布。重复路线判定键为"始发地 + 目的地 + 货品 + 配载方式"四要素组合完全一致；运输方式、货量、单位、备注差异不构成新路线。
6. 只有待货主确认状态的路线可执行确认或驳回。
7. 已确认路线可生成指定托运单，一条路线最多生成一张指定托运单。
8. 不支持多条路线合并生成一张指定托运单。
9. 询价单生成托运单后，后续运输履约状态由托运单承接，货源询价不继续承载运输中等状态。
10. 主单"已完成"判定：货源询价下全部有效路线均到达终态（已生成托运单 或 已取消）。存在长期"待货主确认"或"已驳回"未回流的路线时，主单仍保留在待确认，不进入已完成。
11. 路线"已驳回"不是终态：货主驳回后由无车承运人重新提交报价，重新提交后路线回到"报价中 → 待货主确认"。

## 5. 功能详细说明

### 5.1 货源询价列表页
#### 5.1.1 功能说明
- 功能目的：支持货主集中查看和管理自己发布的货源询价。
- 使用角色：货主。
- 触发入口：货主端菜单“货源询价”。
- 前置条件：当前用户具备货主身份和货源询价查看权限。

#### 5.1.2 页面与交互逻辑
- 默认展示当前货主发布的货源询价。
- 支持按询价类型、发布时间、关键词筛选；主单状态统一通过页面上方状态 Tabs 切换，不再单独提供询价状态下拉筛选。
- 支持点击“新增货源询价”进入新增页。
- 支持查看货源询价详情。
- 草稿状态支持编辑、删除、发布。
- 待承接、待报价、待确认状态支持查看和取消。
- 待确认状态可从操作入口进入详情确认路线。
- 已拒绝、已取消状态支持查看和重新发起。
- 已完成状态支持查看和查看托运单。

#### 5.1.3 校验规则
- 删除草稿需二次确认。
- 取消货源询价需二次确认，且必须填写取消原因。
- 无权限用户不可查看非授权货主的货源询价。

#### 5.1.4 列表字段
| 字段 | 说明 |
|---|---|
| 询价单号 | 系统生成的货源询价编号 |
| 询价标题 | 货主填写的询价标题 |
| 询价类型 | 长协货源询价 / 零星货源询价 |
| 询价对象 | 本张询价单发送给的无车承运人 |
| 路线数量 | 当前货源询价包含的路线总数 |
| 待确认路线 | 待货主确认的路线数量 |
| 已确认路线 | 已确认路线数量 |
| 已生成托运单 | 已生成指定托运单的路线数量 |
| 询价状态 | 草稿、待承接、待报价、待确认、已完成、已拒绝、已取消 |
| 发布时间 | 货主发布货源询价的时间 |
| 操作 | 查看、编辑、删除、发布、取消、确认路线、查看托运单、重新发起 |

### 5.2 新增货源询价页
#### 5.2.1 功能说明
- 功能目的：支持货主创建货源询价并维护多条路线。
- 使用角色：货主。
- 触发入口：货源询价列表页“新增货源询价”。
- 前置条件：当前用户具备新建权限。

#### 5.2.2 页面与交互逻辑
- 页面包含基本信息区、路线明细区、底部操作区。
- 基本信息区填写询价类型、询价标题、货主、询价对象、询价说明。
- 路线明细区支持表格行内新增、模板导入、行内编辑、单条删除、批量删除。
- 点击“新增路线”后，直接在路线明细表格中追加一行空白可编辑行，不通过弹窗新增路线。
- 点击“保存草稿”后保存当前内容，货源询价状态为草稿。
- 点击“发布询价”后执行校验，校验通过后发送至选定的无车承运人，货主侧状态进入“待承接”。

#### 5.2.3 校验规则
- 强校验：询价类型为空不可保存或发布。
- 强校验：询价标题为空不可发布。
- 强校验：货主为空不可发布。
- 强校验：询价对象为空不可发布。
- 强校验：路线明细为空不可发布。
- 强校验：任一路线始发地、目的地、货品、配载方式、货量、单位为空不可发布。
- 强校验：货量必须大于 0。
- 强校验：单位必须符合当前配载方式的可选范围。
- 强校验：同一货主、同一货源询价内重复路线不可发布。
- 弱校验：询价说明、路线备注为空不拦截。
- 二次确认：删除路线、批量删除路线、发布询价均需确认。

#### 5.2.4 基本信息字段
- 询价类型：类型：单选 / 下拉；是否必填：是；展示条件：新增与编辑时展示；可编辑条件：草稿状态可编辑；默认值：空；选项内容/来源：长协货源询价、零星货源询价；校验规则：为空不可发布；错误提示：“请选择询价类型”；联动影响：作为货源询价业务类型展示，本期不影响字段显隐。
- 询价标题：类型：文本框；是否必填：是；展示条件：新增与编辑时展示；可编辑条件：草稿状态可编辑；默认值：空；输入限制：上限50字符；校验规则：为空不可发布；错误提示：“请填写询价标题”；联动影响：作为列表和详情主标题展示。
- 货主：类型：选择字段；是否必填：是；展示条件：始终展示；可编辑条件：草稿状态可编辑；默认值：当前登录所属货主；选项内容/来源：货主企业档案；校验规则：为空不可发布；错误提示：“请选择货主”；联动影响：作为重复路线校验前置条件。
- 询价对象：类型：选择字段；是否必填：是；展示条件：新增与编辑时展示；可编辑条件：草稿状态可编辑，发布后不可修改；默认值：空；选项内容/来源：合作无车承运人企业档案；校验规则：为空不可发布；错误提示：“请选择询价对象”；联动影响：决定本张询价单发送给哪个无车承运人，本期仅支持单选。
- 询价说明：类型：文本域；是否必填：否；展示条件：始终展示；可编辑条件：草稿状态可编辑；默认值：空；输入限制：上限500字符；校验规则：无；联动影响：同步给无车承运人查看。

#### 5.2.5 路线明细字段
- 始发地：类型：下拉选择；是否必填：是；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：空；选项内容/来源：地址库 / 常用地址；校验规则：为空不可发布；错误提示：“请选择始发地”；联动影响：作为重复路线校验维度之一。
- 目的地：类型：下拉选择；是否必填：是；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：空；选项内容/来源：地址库 / 常用地址；校验规则：为空不可发布；错误提示：“请选择目的地”；联动影响：作为重复路线校验维度之一。
- 货品：类型：下拉选择；是否必填：是；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：空；选项内容/来源：货品档案 / 常用货品；校验规则：为空不可发布；错误提示：“请选择货品”；联动影响：作为重复路线校验维度之一，可带出推荐配载方式和默认单位。
- 配载方式：类型：下拉选择；是否必填：是；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：货品推荐值或按重量；选项内容/来源：按重量、按数量、按体积；校验规则：为空不可发布；错误提示：“请选择配载方式”；联动影响：控制单位可选范围。
- 货量：类型：数字输入框；是否必填：是；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：空；输入限制：仅支持正数；整数最多9位；小数最多2位；校验规则：必须大于0；错误提示：“请填写正确的货量”；联动影响：与单位共同作为承运商报价参考基础。
- 单位：类型：下拉选择；是否必填：是；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：根据配载方式带出；选项内容/来源：按重量支持吨、千克，按数量支持件、箱、托、车，按体积支持立方米；校验规则：单位必须符合当前配载方式；错误提示：“请选择正确的单位”；联动影响：与货量共同作为路线规模展示口径。
- 运输方式：类型：单选 / 下拉；是否必填：否；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：汽运；选项内容/来源：运输方式字典；校验规则：无；联动影响：作为路线摘要展示。
- 路线备注：类型：文本框；是否必填：否；展示条件：路线明细行展示；可编辑条件：草稿状态可编辑；默认值：空；输入限制：上限200字符；校验规则：无；联动影响：同步给无车承运人查看。

### 5.3 货源询价详情页
#### 5.3.1 功能说明
- 功能目的：支持货主查看货源询价处理进度、确认路线报价并生成指定托运单。
- 使用角色：货主。
- 触发入口：货源询价列表页“查看 / 确认路线 / 查看托运单”。
- 前置条件：货源询价已创建。

#### 5.3.2 页面与交互逻辑
- 顶部概要区展示询价标题、询价类型、询价状态、路线数量、待确认路线数、已确认路线数、已生成托运单数。
- 基本信息区展示货主、询价对象、询价说明、发布时间。
- 路线明细与进度区展示每条路线状态和关键进度。
- 待确认报价区展示待货主确认的路线及当前最新有效回填价格。
- 指定托运单生成区展示已确认但未生成托运单的路线。
- 若主单状态为已拒绝或已取消，详情页展示对应原因和时间。
- 操作记录区后续可记录发布、回填、确认、生成托运单等动作。

#### 5.3.3 校验规则
- 强校验：仅待货主确认状态路线可确认。
- 强校验：同一路线不可重复确认。
- 强校验：仅已确认且未生成托运单的路线可生成指定托运单。
- 强校验：已生成托运单路线不可重复生成。
- 二次确认：批量确认、批量生成指定托运单需确认。

#### 5.3.4 路线进度字段
| 字段 | 说明 |
|---|---|
| 路线编号 | 系统生成的路线明细编号 |
| 始发地 | 货主原始路线需求 |
| 目的地 | 货主原始路线需求 |
| 货品 | 货主原始路线需求 |
| 配载方式 | 按重量、按数量、按体积 |
| 货量 | 货主填写的路线规模数值 |
| 单位 | 与配载方式联动的计量单位 |

| 指定托运单 | 已生成时展示指定托运单号 |
| 操作 | 确认、驳回、生成托运单、查看 |

### 5.4 路线确认
#### 5.4.1 功能说明
- 功能目的：支持货主对无车承运人提交的路线报价进行确认。
- 使用角色：货主。
- 触发入口：货源询价详情页待确认报价区。
- 前置条件：路线状态为待货主确认。

#### 5.4.2 页面与交互逻辑
- 支持单条确认。
- 支持批量确认。
- 确认前展示路线、货主确认价和最新提交时间。
- 确认成功后路线状态变为已确认。
- 未确认路线继续保留待货主确认状态。
- 支持填写驳回原因；驳回后路线状态变为已驳回，由无车承运人重新提交。

#### 5.4.3 字段规则
- 货主确认结果：类型：操作按钮；是否必填：否；展示条件：待货主确认路线展示；可编辑条件：待货主确认状态可操作；默认值：空；校验规则：仅待货主确认路线可操作；错误提示：“仅待货主确认的路线可确认”；联动影响：确认后路线进入已确认。
- 确认说明：类型：文本域；是否必填：否；展示条件：确认操作时展示；可编辑条件：确认前可编辑；默认值：空；输入限制：上限300字符；校验规则：无；联动影响：作为确认留痕信息。
- 驳回原因：类型：文本域；是否必填：是；展示条件：驳回操作时展示；可编辑条件：驳回前可编辑；默认值：空；输入限制：上限300字符；校验规则：为空不可提交；错误提示：“请填写驳回原因”；联动影响：同步给无车承运人作为重新提交依据。

### 5.5 指定托运单生成
#### 5.5.1 功能说明
- 功能目的：支持货主将已确认路线转换为指定托运单。
- 使用角色：货主、系统。
- 触发入口：货源询价详情页指定托运单生成区。
- 前置条件：路线状态为已确认，且未生成指定托运单。

#### 5.5.2 页面与交互逻辑
- 支持单条路线生成指定托运单。
- 支持多条已确认路线批量生成多张指定托运单。
- 生成成功后展示指定托运单号。
- 不支持多条路线合并生成一张指定托运单。
- 当有效路线均已生成指定托运单后，货源询价状态进入“已完成”。

#### 5.5.3 字段规则
- 生成方式：类型：操作按钮；是否必填：否；展示条件：已确认且未生成托运单路线展示；可编辑条件：符合生成条件时可点击；默认值：空；校验规则：仅已确认路线可生成；错误提示：“仅已确认路线可生成指定托运单”；联动影响：触发指定托运单创建。
- 目标单据：类型：系统生成字段；是否必填：是；展示条件：生成成功后展示；可编辑条件：不可编辑；默认值：系统生成；校验规则：无；联动影响：与原路线建立关联。

### 5.6 取消与重新发起
#### 5.6.1 功能说明
- 功能目的：支持货主在询价未完成前取消询价，并在已拒绝或已取消场景下快速重新发起。
- 使用角色：货主。
- 触发入口：货源询价列表页、详情页。
- 前置条件：询价单状态为待承接、待报价、待确认时可取消；询价单状态为已拒绝、已取消时可重新发起。

#### 5.6.2 页面与交互逻辑
- 取消询价时必须填写取消原因。
- 取消成功后主单状态变为已取消，并在详情页保留取消原因与取消时间。
- 重新发起不在原单上重置状态，而是复制原单基础信息和路线信息生成一张新的草稿询价单。
- 点击重新发起后，应直接进入新草稿的编辑页，并默认带出原单信息，允许货主修改后再发布，而不是直接自动发布。

#### 5.6.3 字段规则
- 取消原因：类型：文本域；是否必填：是；展示条件：取消操作时展示；可编辑条件：提交前可编辑；默认值：空；输入限制：上限300字符；校验规则：为空不可提交；错误提示：“请填写取消原因”；联动影响：作为取消留痕信息。
- 重新发起：类型：操作按钮；是否必填：否；展示条件：已拒绝、已取消状态展示；可编辑条件：符合状态时可点击；默认值：空；校验规则：无；联动影响：复制原单生成新草稿，并进入编辑页继续修改。

## 6. 上下游联动
### 6.1 上游

### 6.2 下游
- 发布后的货源询价进入无车承运人端“询价管理”。

- 货主确认后生成指定托运单，后续履约流程由托运单相关 PRD 承接，货源询价不再继续展示运输中等履约状态。

### 6.3 关联模块
- 询价管理。
- 询价大厅。
- 指定托运单管理。
- 托运单管理。

# 承运商报价页面 PRD

## 一句话说明

承运商根据托运单需求，在页面内完成运输方案设计（单一或多式联运）、路线配置、费用报价和服务承诺填写后，提交报价进入审核流程；货主从多个承运商的报价中确认一个后，基于确认后的报价创建运输计划。

**注：** 提交后的编辑/撤回/重新提交/报价状态锁定等规则，在承运商报价管理PRD中定义，不在本PRD范围内。

---

## 1. 背景与范围

### 1.1 需求背景
- 托运单发布后，承运商可在货源大厅看到托运单并进入报价页面
- 一个托运单可以被多个承运商报价，货主从中选择一个确认
- 报价页面需同时承接托运单需求展示 + 承运商方案填写
- 页面需支持散杂货与集装箱两类业务差异化展示

### 1.2 需求目标
- 支持承运商基于托运单需求快速形成可提交的报价方案
- 支持单一运输方式与多式联运两类方案设计
- 支持引用运输方案作为报价母版，并允许按本次业务继续编辑
- 支持单一运输方式整段报价、多式联运分段报价两类费用组织方式
- 支持散杂货与集装箱两类业务差异化展示
- 支持散杂货多装多卸货品流向在报价路线中的自动承载计算，并对未闭合货品流向做全局提示。
- 支持集装箱托运单已录入节点链在报价页按节点顺序承接，避免承运商仅看到地址而丢失提空、提重、装货、卸货、还空等节点身份。

### 1.3 适用范围
- 用户角色：承运商（登录状态）
- 本期做：左侧托运单信息只读展示、右侧报价表单（运输方案设计、费用明细、其他费用、服务承诺、附件）、页面级提交
- 待讨论：报价详情页（是否有独立的报价详情查看页面？）
- 本期不做：报价管理列表、真实地址服务（高德结构化地址、经纬度、POI匹配）、真实文件上传与持久化、报价审核流、后端持久化、多承运商同时报价冲突处理、版本管理与操作日志

### 1.4 原型状态
- 当前原型目录：`AI输出/原型验证/托运单管理/承运商报价页面/current/`
- 已完成：左右分栏结构、场景切换（散杂货/集装箱）、运输方式选择、运输方案引用、单一/多式联运差异化路线配置、费用配置、服务承诺、附件模拟
- 关键行为已可直接从原型验证：
  - 切换运输方式后，路线与费用直接重置并通过 Toast 提示
  - 切换报价模式后，费用配置直接重置并通过 Toast 提示
  - 运输方案通过弹窗选择，支持搜索、来源通道筛选和分页浏览
  - 单一运输方式下默认通过"装货点顺序 + 卸货点顺序"确认承接顺序；集装箱托运单按设计稿列表结构只读展示托运单集装箱节点，不再使用独立节点顺序模式
  - 多式联运下按路段表维护路线；相邻路段必须首尾相连，路段运输货品由系统按托运单货品流向和路线顺序自动计算
  - 提交报价完成页面内校验后，生成报价和托运订单记录，并跳转托运订单管理页

## 2. 核心链路

```
承运商进入货源大厅，查看托运单
    ↓
进入报价页面，查看左侧托运单需求（只读）
    ↓
填写报价企业信息（联系人、联系电话）
    ↓
选择运输方式（必须在托运单允许范围内）
    ↓
可选：引用运输方案作为母版（带入路线骨架、费用结构）
    ↓
配置路线
    · 单一运输方式：散杂货为装货点顺序 + 卸货点顺序；集装箱为托运单集装箱节点只读承接
    · 多式联运：逐段路线设计
    ↓
配置费用（单一运输方式为整段报价；多式联运为分段报价）
    ↓
填写服务承诺 + 方案概述 + 附件
    ↓
提交报价（生成报价与托运订单）
    ↓
进入托运订单管理，货主可确认报价
    ↓
报价确认后，可继续创建运输计划；多式联运进入创建联运计划
```

**关键决策点：**
- 单一运输方式（公路/水路/铁路）→ 仅支持整段报价
- 多式联运 → 按路段分段报价，不再支持整段报价作为当前报价模式
- 提交后报价 / 托运订单进入"已报价"状态；货主确认后进入"已确认"状态，并作为后续创建运输计划的依据
- 提交后的编辑、撤回、重新报价、审核流和有效期规则仍由后续报价 / 订单管理规则承接

## 3. 核心概念与对象关系

### 3.1 核心对象

| 对象 | 说明 |
|------|------|
| 托运单 | 需求来源，只读展示 |
| 运输方案 | 可引用的母版，来自通道管理 |
| 报价方案 | 承运商本次提交的完整方案 |
| 路线 | 单一运输方式承接列表或多式联运逐段路线 |
| 锚点 | 托运单中的装卸点或集装箱节点，作为报价路线必须覆盖的只读业务节点 |
| 货品流向 | 散杂货从装货节点到卸货节点的货品承接关系，是路段承载货品和路线闭环校验的基础 |
| 路段承载货品 | 多式联运路段中系统根据货品流向自动计算的在途货品，承运商不可手工编辑 |
| 费用 | 整段金额 或 分段金额 |
| 服务承诺 | 配送方式 + 增值服务 + 方案概述 |

### 3.2 状态流转

```
托运单已发布
    ↓
多个承运商可在货源大厅看到托运单，各自提交报价
    ↓
承运商提交报价 → 报价 / 托运订单已报价
    ↓
货主从多个报价中选择一个 → 报价已确认  ← 货主操作
    ↓
基于确认的报价创建运输计划 → 开始执行
```

**注：** 报价审核流的具体规则（是否需要审核、审核节点在哪）、提交后的编辑/撤回规则，在承运商报价管理PRD中定义。

## 4. 核心规则

1. **承运商可选运输方式必须在托运单允许范围内**
   → 不允许超出托运单设定的可报价方式

2. **报价承接范围覆盖是提交强校验**
   → 散杂货及普通简化场景下，托运单的全部装货点和卸货点必须被整体覆盖
   → 集装箱来源为货主提供且托运单已录入扩展节点时，托运单中已录入并纳入本次报价范围的全部节点必须被整体覆盖
   → 覆盖不全则提交被拦截

3. **引用运输方案为一次性带入，不实时绑定**
   → 引用后带入路线骨架和费用结构，但报价页修改不回写原运输方案
   → 切换运输方式或更换引用方案时，当前配置被重置并提示

4. **单一运输方式与多式联运走不同路线设计逻辑**
   → 单一：散杂货为装货点顺序 + 卸货点顺序；集装箱为托运单集装箱节点只读列表承接，不新增独立路线结构
   → 多式联运：锚点只读、路段可编辑；起终点选项来自托运单装卸点或集装箱节点，支持在既有路段中间插入中转点形成新增路段，并要求路段首尾连续

5. **报价费用结构按业务类型和路段运输类型区分**
   → 单一运输方式为整段报价；散杂货整段报价填写运输单价并按托运单配载口径计算，集装箱整段报价展示箱型价格明细表（箱种 / 尺寸 / 货品 / 箱数 / 单价 / 金额）
   → 多式联运为分段报价；每个路段各自维护费用，集装箱运输路段展示箱型价格明细表，散货运输路段展示单价和计费条件
   → 多式联运路段 `carryForm`（运输类型）默认等于托运单业务类型，但允许承运商在路段级调整为散货运输或集装箱运输
   → 散杂货托运单允许在部分路段切换为集装箱运输（散改集），集装箱托运单也允许路段级切换运输形态；当前阶段不在报价页过早锁死运输形态

6. **集装箱货主供箱场景不强制补齐完整提还箱链路**
   → 托运单仅需录入货主当前明确且希望纳入本次承接范围的节点
   → 未录入节点不脑补、不自动追加，也不纳入本次报价强校验

7. **一个托运单可有多个承运商报价，货主从中确认一个**
   → 承运商提交后生成报价记录和托运订单，初始状态为"已报价"
   → 货主确认后报价进入"已确认"状态
   → 已确认的报价可作为创建运输计划的依据

8. **散杂货多式联运路段货品采用在途承载口径**
   → 计算对象不是货品名称汇总，而是托运单发布时形成的每条货品流向明细，即装货节点编号 / 卸货节点编号 / 货品 / 包装 / 配载单位 / 数量
   → 同名货品如存在不同装货点、卸货点或来源批次，应按多条货品流向分别参与路段承运计算；展示时可合并同路段同货品摘要，但不能丢失底层流向
   → 货品装货点出现在路线中后，从装货点所在路段开始进入后续路段
   → 若卸货点出现在路线中，到卸货点所在路段结束；卸货点所在路段仍展示该货品，表示该段运输至卸货点
   → 若卸货点未出现在路线中，该货品持续展示到路线结束，并在路线区底部做全局未闭环提示
   → 若装货点未出现在路线中，该货品不进入任何路段承载货品，并在路线区底部提示装货点缺失

9. **集装箱路线按托运单节点链承接，不按散杂货装卸流向计算**
   → 单一运输方式下，若托运单已录入集装箱节点链，报价页在原承接列表位置按托运单原始节点顺序只读展示，不允许删改节点、调整顺序或修改节点类型
   → 多式联运下，托运单集装箱节点作为只读锚点和必须覆盖的业务节点；路段表起终点选项从散杂货装卸点切换为集装箱节点，承运商可在相邻业务节点之间补充承运商常用地址作为中转点，但不能替代托运单节点
   → 同一地址若对应不同节点类型，必须按节点类型 + 地址作为不同业务节点识别，例如同一地址的提空、装货、卸货、还空不能合并成一个普通地址
   → 集装箱路段承运内容以整票箱信息、箱型价格和集装箱承运标识为主，不按散杂货多装多卸闭环提示口径处理
   → 已录入并纳入本次承接范围的集装箱节点缺失或顺序错误时，在路线区底部做全局错误提示并阻断提交

10. **多式联运每个路段下方必须展示该路段运输货品 / 箱货承运信息**
   → 散杂货路段下方展示该路段正在承运的货品摘要，来源为系统按路线顺序和货品流向自动计算，承运商不可手工改货品或重量
   → 散杂货展示建议为 `货品名称｜包装｜数量+单位`，同一段内多条货品用分号分隔；同名货品是否合并只影响展示，不改变底层流向明细
   → 集装箱路段下方展示集装箱承运标识、箱货摘要或箱型价格明细入口，来源为托运单整票箱信息，不展示散杂货式装卸流向
   → 某路段计算不到散杂货承运货品时，路段货品区域保持为空，不展示“未识别到运输货品”等局部警告
   → 路段货品 / 箱货承运信息为只读计算结果，用于承运商理解报价范围，也作为后续创建联运计划执行段承运货品的上游依据

11. **路线错误提示统一放在路线区全局提示中**
   → 路段级不展示“未识别到运输货品”等局部警告，避免把整条货品流向未闭环误解为单个路段没有装货
   → 装货点缺失、卸货点缺失、装卸顺序错误、货品流向未闭环统一在路线区底部汇总展示

## 5. 功能详细说明

### 5.1 左侧托运单信息展示区（只读）

**托运单基础信息：**
- 托运单编号、业务类型、发布方式、托运企业、联系人、联系电话

**运输需求摘要：**
- 散杂货：按托运单节点顺序展示，先展示全部装货点，再展示全部卸货点；装货点下展示该点货品配载和去向拆分，卸货点下按货品名称 + 包装 + 单位做展示层合并并保留来源拆分。
- 集装箱：展示集装箱来源 + 箱型箱量 / 箱货摘要 + 节点信息；箱型箱量摘要按托运单 `containerBoxes` 汇总，需体现箱种、尺寸、货品名称和数量；当托运单已录入提空、提重、装货、卸货、还重、还空等节点时，按托运单实际录入顺序展示完整节点链。
- 数据层货品流向不因展示合并而丢失；报价路线覆盖、路段承载货品和后续计划承接仍使用原始装卸关系。

**报价要求卡片：**
- 可报价运输方式、主方式/偏好方式、报价截止时间、期望价格、支付方式偏好

**状态：只读，不可编辑。不允许在当前页面内修改托运单数据。**

### 5.2 报价企业信息区

- 报价企业：系统自动带出当前登录承运商企业，不可修改
- 联系人：默认带出当前登录用户信息，可修改
- 联系电话：默认带出当前登录用户信息，可修改

### 5.3 运输方式、运输方案与报价模式

**运输方式：**
- 单选，取值范围：托运单"可报价运输方式"内的选项
- 切换时：清空引用方案 + 重置路线与费用配置 + Toast 提示"切换运输方式后引用方案、路线与费用已重置，请重新配置"

**引用运输方案（可选）：**
- 点击字段后打开方案选择弹窗（不是普通下拉框）
- 弹窗筛选条件：符合当前运输方式 + 启用状态 + 方案名称搜索 + 来源通道筛选 + 分页展示
- 方案列表字段：方案名称、来源通道、绑定路径、标准服务组合摘要、标准价格结构摘要、标准时效摘要、更新时间
- 引用后带入：路线骨架、报价模式、标准价格结构、标准其他费用、标准服务组合、标准时效口径
- 引用关系为一次性带入，报价页修改不回写原运输方案
- 更换引用方案时：提示"当前路线、费用、服务配置将被新方案覆盖"，确认后执行替换

**报价模式：**
- 单一运输方式：仅支持整段报价
- 多式联运：仅支持分段报价，每个运输路段维护一组费用
- 切换运输方式导致报价模式变化时：重置当前费用配置 + Toast 提示"已切换运输方式，当前费用配置已重置"

### 5.4 路线设计

**单一运输方式：**
- 默认场景下，装货点下拉仅展示托运单装货点；同一地址在组内不可重复选择；最少选1个；支持组内顺序调整
- 默认场景下，卸货点下拉仅展示托运单卸货点；同一地址在组内不可重复选择；最少选1个；支持组内顺序调整
- 若为集装箱托运单，则在原承接区按设计稿列表结构只读展示托运单集装箱节点；节点行需展示节点类型和地址，用于区分同地址下的提空、装货、卸货、还空等不同业务节点
- 集装箱节点列表按托运单原始录入顺序锁定展示，不允许删除节点、不允许调整顺序、不允许修改节点类型
- 上述两类场景均不支持新增托运单外地址，不支持新增自由路段
- 单一运输方式仅支持整段报价，不允许切换分段报价。

**多式联运：**
- 逐段路线设计（起点→途经→终点），页面以路段表形式维护运输方式、运输类型（carryForm）、起点、终点和时效
- 未引用方案时：默认根据托运单节点生成骨架；散杂货默认以装货点、承运商常用中转点、卸货点形成初始路线，集装箱优先按集装箱节点链形成骨架
- 已引用方案时：优先承接方案主路径骨架，可继续调整
- 支持新增/删除路段；新增路段的业务含义是在已有路线中间插入一个中转点，并自动拆分相邻路段，不是新增一条脱离原路线的独立路径
- 路段必须首尾相连，形成连续路线
- 首末段起终点与托运单不一致：给出提示性 Toast，不阻止提交
- 地址选项底层区分托运单地址和承运商常用地址；承运商常用地址可作为中转节点，不参与装卸匹配。
- 散杂货路段下方展示只读运输货品；系统按在途承载口径自动计算，承运商不可手工改货品或重量；每条货品流向独立参与计算，支持多装多卸、多货品和同名货品多来源。
- 集装箱业务地址下拉展示节点类型前缀，避免只展示地址名导致提空、装货、卸货、还空等节点身份丢失。
- 集装箱多式联运路线以托运单已录入节点链为业务主线；报价路段可在业务节点之间插入承运商常用地址，但托运单节点必须以原节点身份被覆盖。
- 集装箱同一地址出现多个节点类型时，不按地址名称去重；系统按节点编号 / 节点类型 / 地址组合识别路线节点。
- 集装箱路段下方展示集装箱承运标识、箱货摘要或箱型价格明细入口；费用区按托运单整票箱信息带出箱型价格明细，计费条件固定为按集装箱。
- 多式联运路段可维护运输类型 `carryForm`：散货运输 / 集装箱运输；默认等于托运单业务类型，但允许路段级修改。运输类型影响分段计费条件，集装箱运输段按箱型价格明细报价，散货运输段按单价和计费条件报价。

**覆盖校验：**
- 散杂货及普通简化场景下，托运单的装货点和卸货点需在报价方案中被整体覆盖
- 集装箱货主供箱且托运单已录入扩展节点时，托运单中已录入并纳入本次报价范围的全部节点需被整体覆盖
- 集装箱覆盖校验按节点身份校验，不只按地址文本校验；节点类型不同但地址相同的节点必须分别覆盖。
- 集装箱节点顺序应遵循托运单原始节点链顺序；若路线中出现已录入节点顺序倒置，提交报价时拦截。
- 覆盖不全：提交时被拦截；散杂货提示具体货品缺失的装货点或卸货点，集装箱提示缺失的节点类型和地址
- 散杂货装货点晚于卸货点时提交拦截，并提示具体货品和节点顺序错误
- 路段级未计算出散杂货运输货品时，路段货品区域保持为空，不展示局部警告；集装箱路段按箱货摘要 / 集装箱承运标识表达，不套用散杂货空货品警告
- 多条货品流向存在错误时，路线区底部汇总展示全部错误；提交时可取第一条错误做阻断提示
- 当前地址输入仍为文本模拟，正式结构化地址与后端强校验口径待确认

### 5.5 费用明细

**整段报价：**
- 仅用于单一运输方式，配置一组整体费用
- 散杂货业务展示运输单价、计费依据和金额计算结果，保持原散杂货整段计费依据
- 集装箱业务展示箱型价格明细表，字段至少包含箱种、尺寸、货品名称、箱数、单价、金额；箱型价格行按托运单箱信息唯一键生成

**分段报价：**
- 仅用于多式联运，按路线逐段配置费用，同步显示运输方式和运输类型标识
- 必须覆盖全部路段
- 分段报价按路段维护计费条件、单价、路段金额和路段其他费用
- 散货运输段可选按重量、按体积、按车等计费条件；按重量时按该路段承载货品重量计算
- 集装箱运输段计费条件固定为按集装箱，并通过箱型价格明细维护箱型单价

**散杂货：**
- 计费条件：自动继承托运单配载方式（按重量/按体积/按数量），不可修改
- 计费依据：单选，选项为"按装货口径" / "按卸货口径"，必选
- 填写运输单价，自动计算金额

**集装箱：**
- 整段报价或路段 `carryForm=集装箱运输` 时，计费条件为"按集装箱"
- 不需要选择计费依据
- 通过箱型价格明细表配置各箱型单价（根据托运单箱种 + 尺寸 + 货品名称自动生成行）
- 箱租等非运输费用在"其他费用"中单独配置

**金额展示：**
- 整数部分千分位格式化
- 保留2位小数
- 单位后缀（元）

**注：** 整段报价不再强制维护独立的"预计运输时效"必填字段；分段报价中的路段时效为补充信息，不作为提交阻断条件。

### 5.6 其他费用

- 支持新增/删除费用项
- 费用类型：单选，选项为"增项" / "减项"，默认选中"增项"
- 费用名称：文本框，上限50字符，不可为空
- 计价方式：单选，选项为"单价×基数" / "固定金额"
- 金额：单价×基数时自动计算；固定金额时等于计价数值
- 其他费用与增值服务不自动联动，如需收费需手动在本区配置

### 5.7 服务承诺

- 配送方式：多选，至少选择一种，不选则提交校验不通过
- 增值服务：多选，可补充"其他"选项，选中后显示文本框供填写说明（上限100字符）
- 方案概述：多行文本框，补充服务范围和特殊说明，上限500字符，提交报价时必填
- 附件：模拟上传与删除，显示文件名列表，可删除；本期不做真实文件上传与持久化

### 5.8 页面级提交

**提交报价：**
- 执行完整校验：报价企业联系人、联系电话、路线覆盖（强校验）、费用必填、配送方式、方案概述
- 校验通过：生成报价记录和托运订单记录；报价 / 托运订单初始状态为 `已报价`
- 提交成功后跳转托运订单管理页，由货主在托运订单管理中确认报价
- 当前页面提交成功后不可继续编辑
- 不提供"保存草稿"能力

**提交后的管理规则（报价管理PRD中定义）：**
- 提交后是否允许撤回/重新编辑
- 货主确认报价后的锁定规则
- 报价有效期与过期处理
- 能否重新报价

## 7. 字段说明

### 7.1 报价企业信息

- **报价企业**：类型：文本；展示条件：页面加载时自动带出；可编辑条件：否（不可修改）；来源：当前登录承运商企业
- **联系人**：类型：文本框；是否必填：是；输入限制：上限20字符，不可输入特殊字符；默认值：当前登录用户；校验规则：为空不可提交；错误提示："请填写联系人"
- **联系电话**：类型：文本框；是否必填：是；输入限制：手机号（11位数字）或固定电话（区号-号码）；默认值：当前登录用户；校验规则：格式校验，格式错误提示"请输入正确的电话号码"；错误提示："请填写联系电话" / "请输入正确的电话号码"

### 7.2 运输方案设计

- **运输方式**：类型：单选；是否必填：是；选项来源：托运单"可报价运输方式"；切换效果：清空引用方案 + 重置路线与费用 + Toast 提示
- **运输方案**：类型：弹窗选择；是否必填：否；展示条件：点击后打开方案选择弹窗；弹窗筛选：符合当前运输方式 + 启用状态 + 方案名称搜索 + 来源通道筛选 + 分页展示；引用效果：带入路线骨架、报价模式、标准价格结构、标准其他费用、标准服务组合、标准时效口径；更换引用效果：提示覆盖，确认后替换

### 7.3 路线设计（单一运输方式）

- **装货点顺序**：类型：多选下拉；是否必填：是；展示条件：运输方式为单一运输方式，且未命中“集装箱 + 货主提供箱子 + 已录入扩展节点”场景；选项来源：仅展示托运单装货点；输入限制：同一地址在组内不可重复选择；最少选1个；可编辑条件：当前路线未锁定时可编辑；支持拖拽调整顺序；联动影响：变更后费用试算结果可能变化
- **卸货点顺序**：类型：多选下拉；是否必填：是；展示条件：运输方式为单一运输方式，且未命中“集装箱 + 货主提供箱子 + 已录入扩展节点”场景；选项来源：仅展示托运单卸货点；输入限制：同一地址在组内不可重复选择；最少选1个；可编辑条件：当前路线未锁定时可编辑；支持拖拽调整顺序
- **集装箱节点承接列表**：类型：锁定展示列表；是否必填：是；展示条件：运输方式为单一运输方式且业务类型为集装箱；取值来源：托运单已录入并纳入本次报价范围的集装箱节点；输入限制：按托运单原始录入顺序展示；可编辑条件：否（不可删除、不可改序、不可修改节点类型）；展示规则：节点行需展示节点类型 + 地址，避免同地址不同节点身份被合并；联动影响：作为覆盖校验与报价承接范围的直接依据

### 7.4 路线设计（多式联运）

- **路段起点/终点**：类型：文本/下拉；是否必填：是；展示条件：运输方式为多式联运；输入限制：首段起点与托运单装货点相关联；末段终点与托运单卸货点相关联；相邻路段首尾相连；可编辑条件：当前路段未锁定时可编辑；支持新增/删除路段；校验规则：首末段与托运单不一致时给出提示性 Toast，不阻止提交
- **路段运输方式**：类型：下拉；是否必填：是；展示条件：运输方式为多式联运；可选值：公路、水路、铁路；联动影响：后续创建计划时作为报价小段聚合执行段的重要依据。
- **路段运输类型**：类型：下拉；是否必填：是；展示条件：运输方式为多式联运；可选值：散货运输、集装箱运输；联动影响：影响该路段费用计费条件和后续计划承接表达。
- **路段运输货品 / 箱货摘要**：类型：只读展示；展示条件：多式联运路段下方；取值来源：散杂货按托运单货品流向和路线顺序自动计算，集装箱以托运单整票箱信息、路段集装箱承运标识和费用区箱型价格明细为主；展示规则：散杂货展示 `货品名称｜包装｜数量单位`，多货品用分隔符连续展示；集装箱展示箱种、尺寸、货品名称、箱量或“集装箱承运”标识；可编辑条件：否；空值处理：散杂货为空时保持空白，不展示局部警告。
- **集装箱路线节点身份**：类型：内部识别规则；展示条件：业务类型为集装箱；取值来源：托运单集装箱节点编号 / 节点类型 / 地址；校验规则：同地址不同节点类型不能合并，缺失或顺序错误时进入路线错误汇总。
- **路线错误汇总**：类型：全局提示；展示条件：路线存在缺失装货点、缺失卸货点、装卸顺序错误、集装箱节点未覆盖等错误；展示位置：路线规划区底部；联动影响：提交报价时阻断。

### 7.5 费用明细

- **计费条件（散货运输）**：类型：文本 / 下拉；是否必填：费用必填时必填；展示条件：整段散杂货报价或分段报价路段 `carryForm=散货运输`；默认值：整段时继承托运单配载方式，分段时按路段计费条件选择；展示值："按重量"、"按体积"、"按数量"或"按车"
- **计费条件（集装箱运输）**：类型：文本（按集装箱）；是否必填：否；展示条件：整段集装箱报价或分段报价路段 `carryForm=集装箱运输`；默认值：按集装箱
- **计费依据**：类型：单选；是否必填：是（散杂货必填）；展示条件：业务类型为散杂货；选项内容："按装货口径" / "按卸货口径"；校验规则：为空不可提交；错误提示："请选择计费依据"
- **运输单价**：类型：数字输入框；是否必填：是（费用必填时）；输入限制：整数最多9位；小数最多2位；仅允许正数（含0）；校验规则：为空或0则提交校验不通过；错误提示："请填写运输单价"；联动影响：影响金额计算结果
- **金额**：类型：计算展示；展示条件：填写运输单价后自动计算；展示格式：整数千分位 + 2位小数 + 单位后缀（元）；计算公式：= 运输单价 × 计费基数；可编辑条件：否（只读）
- **箱型价格明细**：类型：明细表；是否必填：是（费用必填时）；展示条件：整段集装箱报价或分段报价路段 `carryForm=集装箱运输`；输入限制：根据托运单箱种 + 尺寸 + 货品名称自动生成行；每行包含箱种、尺寸、货品名称、箱数、单价、金额；仅支持正数（含0）；小数最多2位；校验规则：行为空时提示"请填写箱型单价"
- **整段总金额**：类型：数字展示；展示条件：整段报价模式；展示格式：整数千分位 + 单位后缀（元）；可编辑条件：否（只读）
- **路段运输类型 carryForm**：类型：下拉；展示条件：多式联运路段；可选值：散货运输、集装箱运输；默认值：托运单业务类型对应运输形态；可编辑条件：可编辑；联动影响：决定路段费用结构和后续计划承接表达，支持散改集等真实业务场景。
- **路段计费条件**：类型：下拉；展示条件：分段报价；可选值：散货运输段支持按重量、按体积、按车，集装箱运输段固定按集装箱；联动影响：决定路段金额计算方式。
- **路段箱型价格明细**：类型：明细表；展示条件：分段报价且路段运输类型为集装箱运输；取值来源：托运单箱种 + 尺寸 + 货品名称；校验规则：费用必填时需填写对应箱型单价。

### 7.6 其他费用

- **费用类型**：类型：单选；是否必填：是（新增时）；选项内容："增项" / "减项"；默认值："增项"
- **费用名称**：类型：文本框；是否必填：是；输入限制：上限50字符；校验规则：为空不可提交；错误提示："请填写费用名称"
- **计价方式**：类型：单选；是否必填：是；选项内容："单价×基数" / "固定金额"
- **计价数值**：类型：数字输入框；是否必填：是；输入限制：仅支持正数；小数最多2位；展示条件：整段报价模式填总金额，分段报价模式填单价或固定金额

### 7.7 服务承诺

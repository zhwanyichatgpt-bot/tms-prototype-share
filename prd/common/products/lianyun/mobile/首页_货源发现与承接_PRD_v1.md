# 移动端首页——货源发现与承接 PRD

## 第 0 章 快速理解

企业用户通过统一首页浏览货源、运输方案与物流企业；承运商进入货源详情后，根据发布方式提交报价，或按货主定价抢单。

**核心决策**

- 首页三个 Tab 使用同一套展开、上滑收起和列表浏览机制，不另加“推荐货源／全部货源”入口行。
- 报价与抢单是独立办理分支：报价等待货主选择；抢单成功直接确定承运商、进入待执行。
- 查看我的报价必须回显提交时的完整明细，不能只剩一个金额。
- 抢单后的履约归入托运订单，保持 Web 业务归属，不新增“我的接单”。

本期包含首页发现、货源详情、收藏与联系入口、报价填写与核对、已报价回看、抢单核对与结果。运输助手指定托运见对应独立 PRD，不与货源抢单混用。

**阶段**：用户已认可本轮原型并要求沉淀；本文待评审。真实交易、权限、消息与托运订单接入未因本地演示而完成。

## 第 1 章 背景、目标与范围

### 1.1 背景与目标

此前演示以报价为主，缺少抢单分支；报价回看也曾仅展示金额。首页推荐内容与全部列表曾被拆成不同外观和入口，影响连续浏览。

本轮目标是让企业用户在一致的手机界面中找到货源、看懂参与方式、核对承运条件，并在提交后查看自己实际提交的内容与结果。

### 1.2 角色与范围

| 角色 | 主要动作 | 结果或边界 |
|---|---|---|
| 公共内容浏览者 | 切换分类、查看货源及企业信息 | 浏览不等于拥有报价或抢单资格 |
| 承运商 | 报价、抢单、查看本人企业参与结果 | 不可修改货主固定抢单价格 |
| 货主 | 发布定价与要求、选择报价承运商 | 抢单成功不再等待货主二次选定 |

不包含新增独立接单管理页、报价编辑撤回流程、真实拨号发送、生产抢占服务和完整履约页面。

## 第 2 章 角色视角流程

### 2.1 首页发现

1. 用户在首页选择精选货源、运输方案或物流企业，展开态保留查询与行业服务区域。
2. 上滑浏览时，上部内容自然收起，地区／发布入口、三个 Tab 及分类筛选保持可用，继续浏览当前分类列表。
3. 下滑回到顶部，恢复展开态；收起态切换 Tab，保持收起浏览状态。
4. 点击卡片进入相应详情；货源卡片根据报价或抢单方式进入对应流程。

### 2.2 报价

1. 承运商查看货源、装卸要求和可报价运输方式，进入运输安排。
2. 编排路线或引用方案，配置费用与服务，填写报价联系信息和方案概述。
3. 进入核对报价，核对路段、计费说明、金额汇总、服务及联系人。
4. 提交成功后货源显示已报价；点击“查看我的报价”，回显本次提交明细。报价后由货主选择承运商，不直接进入待执行。

### 2.3 抢单

1. 承运商查看货主定价、支付方式、装卸地点时间及承运要求，进入核对抢单。
2. 核对固定价格与条件并确认抢单；价格和费用范围不可在此修改。
3. 抢单成功直接确定当前承运商，进入待执行；详情可“查看抢单详情”。后续在托运订单中办理。
4. 已抢完、已截止或条件已变化时，不按旧条件继续抢单；条件变化需重新核对。

## 第 3 章 核心对象与状态

### 3.1 对象关系

货源承接方式决定参与流程；报价记录保存承运商提交的方案与费用，抢单记录保存成功时的价格与承运条件。参与标记属于当前企业对这条货源的参与结果，不等于货源对所有企业的统一状态。

### 3.2 状态与操作

| 对象／状态 | 进入条件 | 当前承运商可用操作 | 结果与限制 |
|---|---|---|---|
| 报价货源／未报价 | 尚无本人企业报价 | 提交报价 | 成功后显示已报价 |
| 报价记录／已报价 | 报价已保存成功 | 查看我的报价、返回货源详情 | 不作为承运商已被选定的证明 |
| 抢单货源／可抢 | 有效且尚未被承接 | 核对并确认抢单 | 成功后确定承运商、待执行 |
| 抢单记录／待执行 | 当前企业抢单成功 | 查看抢单详情，后续到托运订单办理 | 不重复抢单、不再要求货主选定 |
| 抢单货源／已抢完 | 已由其他承运商承接 | 查看不可抢结果 | 不允许再次确认抢单 |
| 抢单货源／已截止 | 已到或超过抢单截止时间 | 查看截止结果 | 不允许确认抢单 |

### 3.3 联动结果

- 报价成功：生成本人企业报价记录，关联货源打“已报价”标记，默认发现列表仍可展示该货源。
- 抢单成功：记录承运商与成功条件，进入待执行；从默认推荐及货源发现列表移出，避免继续作为可抢货源展示。
- 已抢完、已截止的抢单货源不进入默认发现列表；已打开详情应能反馈对应结果。

## 第 4 章 核心业务规则

### R01：三个 Tab 同页滚动，沿用已确认设计

精选货源、运输方案、物流企业共用首页展开／收起机制。推荐到全部列表通过连续上滑浏览完成，不展示“推荐货源／全部货源”入口行，不跳到另一套大厅外观。分类卡片保留各自业务内容，货源卡片沿用已确认首页设计，不能把三个 Tab 的字段强行做成相同内容。

### R02：参与方式和价格须分开表达

卡片与详情明确区分报价、抢单及本人企业参与状态。金额带对应的元／票、元／吨或元／箱等单位；无明确价格时显示“面议”，不叫“邀约报价”。“面议”只表示价格未明确，不改变该货源的报价办理方式。

### R03：报价核对与回看使用同一份提交内容

核对报价按路段运输明细、费用汇总、配送及增值服务、报价联系信息、方案概述排列。回看以提交时内容为准，只读展示，不用当前表单默认值或货源后续变化替换历史报价。

- 路段展示运输方式、运输形态、起终点；分段报价在相应路段展示计费说明与金额。
- 散杂货展示计费条件、装／卸货口径、计费基数、单价与金额；集装箱按箱型、箱数及对应单价展示，不能只给总金额。
- 单路段整票报价把费用并入该路段卡；多路段整票报价单列整票费用，不能在每段重复计入整票金额。
- 汇总为运输费合计、增项费用、减项费用、报价合计，报价合计＝运输费合计＋增项费用－减项费用。设计稿示例数字不作为计算规则或成交价。
- 联系人回看按设计脱敏展示电话；提交时间仅作为回看记录信息。
- 无完整历史明细的旧记录只展示已留存总价、时效及费用说明，并说明缺少路段、费用拆分或服务信息；不得补造历史数据。

### R04：报价方式不改变承运范围和金额口径

单一运输方式整票报价；本轮 App 多式联运支持整票与分段报价。整票只计算一次整票费用，分段按各段费用汇总。路线必须满足原托运要求，引用方案不回写原方案。配送方式、联系人和方案概述等既有提交校验继续适用。

Web 既有 PRD 的多式联运分段限定不在本次直接改写；跨端统一报价模式及其下游承接规则见第8章衔接项。

### R05：抢单按货主定价确认，不转为承运商报价

核对页展示货主定价、计算数量及单位、总额、费用包含／不包含与支付方式。按发布计价数量乘单价计算；集装箱多箱行分别计算后汇总。抢单时不可改价或新增一份承运商报价。

确认前重新核实可抢状态与价格条件；成功后直接确定承运商、进入待执行。重复确认不能产生第二次成功承接；其他承运商已抢走或截止时返回相应不可抢结果。正式抢占一致性需由服务端实现，本机模拟不能证明生产并发安全。

### R06：抢单核对保留关键条件，其他信息本页展开

默认展示价格与费用范围、支付方式、货品货量、装卸地点时间和关键运输要求。其他托运信息在本页折叠展开；不重复堆放详情全文，不因折叠遗漏承运商确认所必需的条件。底部保留确认勾选、返回详情、确认抢单。

### R07：报价和抢单成功后的去向不同

报价后显示“查看我的报价”，不把报价提交成功表述为抢单成功。抢单后显示“查看抢单详情”，不使用含义不清的“查看承接”；后续履约归入托运订单，当前原型未接通时不得假装已经跳入订单。

## 第 5 章 功能详细说明

### 5.1 首页推荐与完整列表

沿用 Pixso 已确认首页样式及共享货源卡。展开态优先看到推荐内容，继续上滑进入同页完整列表；三个 Tab 的筛选与列表随当前分类联动。卡片展示装卸日期、起终点、货品货量、运输标签、价格、发布企业及发布时间；匹配度有可用结果时展示，不把示例匹配度固定为业务结论。

### 5.2 货源详情

展示货源办理方式、货品、装卸安排、地点与托运要求、发布企业和联系信息，支持收藏及联系入口。未参与时进入报价或抢单；已参与时使用 R07 对应回看按钮。参与标记与首页卡片保持一致。

### 5.3 报价填写、核对与回看

按运输安排→费用与服务→核对报价三步组织。核对页按 Pixso「报价-核对报价」画板182:9997还原卡片、计费条、费用汇总及底部报价合计与主按钮，不增加设计稿之外的逐路段修改按钮。需要修改时通过返回进入填写步骤；回看以“我的报价／已报价”说明状态，底部返回货源详情。

新报价保存完整提交内容；失败不显示已报价或覆盖既有成功内容。真实报价管理中的编辑、撤回和重报不在此增加。

### 5.4 抢单核对与结果

按 R05、R06 核对固定价格及条件。成功展示待执行与抢单成功信息，并可回看成功时条件。不可抢时明确显示已抢完或已截止；价格条件变化时返回重新核对，不继续提交旧条件。

## 第 7 章 字段与枚举

### 7.1 货源与参与信息

| 字段组 | 展示与来源 | 可编辑条件 | 联动 |
|---|---|---|---|
| 承接方式 | 货主发布的报价／抢单方式 | 浏览及核对只读 | 决定详情主按钮及后续流程 |
| 参与标记 | 本人企业已报价／已抢单结果 | 只读 | 关联卡片、详情和回看 |
| 价格 | 货主发布价或明确参考值，附单位；未知显示面议 | 抢单不可改价 | 不把参考价当成承运商已提交价 |
| 装卸日期与地点 | 货源发布时间要求及节点地址 | 核对只读 | 与运输时效分开表达 |
| 货品货量 | 原托运货品、数量和计量单位 | 核对只读 | 形成计费基数或箱型行 |

### 7.2 报价核对与历史回看

| 字段组 | 展示内容 | 来源与条件 |
|---|---|---|
| 运输明细 | 方式、运输形态、起终点、计费说明、路段金额 | 承运商填写；整票／分段按 R03 |
| 费用汇总 | 运输费、增项、减项、报价合计 | 按实际填写计算；只读 |
| 服务 | 配送方式、增值服务；未选增值服务显示未选择 | 承运商已选内容 |
| 报价联系信息 | 企业、联系人、脱敏电话 | 提交时企业与联系信息 |
| 方案概述 | 承运方案说明 | 提交内容；回看不替换为默认说明 |
| 提交时间 | 本次提交时间 | 提交成功后的记录信息 |
| 旧记录缺失说明 | 明确哪些明细未留存 | 仅历史内容不足时展示 |

### 7.3 抢单核对

价格数量、单价、计价单位、计算总额、费用范围、支付方式、货品、装卸节点及时间、截止时间和承运要求均来自发布条件；确认勾选由承运商操作，不能代替服务端可抢校验。

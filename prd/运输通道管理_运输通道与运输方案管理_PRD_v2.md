# 运输通道与运输方案管理 PRD

## 0. 一句话说明

运输通道用于沉淀企业内部"怎么走"的运输能力资产，运输方案用于基于来源通道继续沉淀"怎么卖"的标准经营母版；用户先维护通道边界、路径和能力，再按来源通道与主路径配置方案，后续报价只引用方案内容生成正式结果，不与方案实时绑定。

## 1. 背景与范围

### 1.1 需求背景

- 历史讨论中，运输通道一度同时承载路径、经营方案、价格、承运商和发布信息，导致对象边界混乱，页面越来越像“第二个报价页”。
- 研发评审和原型验证过程中，围绕发布状态、驳回处理、通道与方案计费口径、方案抽屉管理方式等问题又产生了一轮新收敛，原有 PRD 已不能完整代表最新结论。
- 如果不把这一轮结论正式回写，后续研发会在“通道展示摘要”和“方案标准经营母版”之间再次混用，测试也无法按统一状态链路设计用例。

### 1.2 需求目标

- 明确运输通道与运输方案的对象边界，确保“通道负责怎么走，方案负责怎么卖”不再回退。
- 统一运输通道本体状态、发布状态、运输方案状态三套状态口径，并明确关键状态流转。
- 将运输通道管理、通道新增/编辑、方案管理抽屉、新增运输方案四个页面的字段、交互、校验和上下游联动收敛到一份可直接给研发落地的主 PRD。
- 统一通道层与方案层的计费依据口径，避免两个页面继续维护两套费用表达。

### 1.3 适用范围

- 适用角色：经营维护人员、方案配置人员。
- 适用场景：企业内部长期维护运输能力资产，并基于已沉淀的运输通道生成可复用的标准运输方案。
- 适用业务类型：单一运输方式场景（公路 / 水路 / 铁路）和多式联运场景。
- 本期覆盖页面：
  - 运输通道管理页
  - 新增 / 编辑 / 查看运输通道页
  - 运输方案管理页（当前以运输通道页右侧抽屉承接）
  - 新增 / 编辑运输方案页

### 1.4 非本期范围

- 本期不做：
  - 真实方案大厅页面与完整审核后台
  - 真实后端接口、真实权限体系、日志体系、版本历史
  - 报价详情页、方案详情页独立设计
  - 地图服务、结构化地址服务、真实文件上传能力
  - 运输方案被引用后的正式报价、审核、执行调度链路
- 待讨论：
  - 路径区正式版本是否需要拖拽排序 / 指定位置插入能力
  - 通道展示摘要后续是否需要更多结构化自动汇总能力

### 1.5 原型状态

- 当前原型目录：`AI输出/原型验证/运输通道管理/current/`
- 当前已完成并通过验证的页面产物：
  - `page.html`：运输通道管理页、通道新增/编辑页、运输方案管理抽屉
  - `scheme-create.html`：新增运输方案页
  - `spec.yaml` / `spec-scheme-create.yaml`：研发标注说明
- 当前已验证通过的关键行为：
  - 通道发布状态已收口为 `未发布 / 待审核 / 已发布 / 已下架 / 已驳回`
  - 管理页动作文案统一为 `发布 / 撤回 / 下架 / 停用`
  - `已驳回` 在列表展示 1 行驳回原因摘要，在编辑页展示完整驳回信息
  - 运输方式列已去除解释性灰色副文案
  - 通道层和方案层统一使用 `计费依据`
  - 方案抽屉与新增运输方案页的研发标注已补齐并完成可点击验证
- 研发阅读入口以原型标注为准；本 PRD 作为正式业务主文档，和标注口径保持一致。

## 2. 核心链路

```text
用户进入运输通道管理页，筛选并查看既有通道
    ↓
新建或编辑运输通道，维护通道边界、路径结构、服务能力、展示摘要
    ↓
保存草稿 或 保存并启用
    ↓
启用后的通道可发起发布，进入待审核，审核通过后对外可发布
    ↓
用户在通道管理页点击“查看方案”，打开当前通道的运输方案管理抽屉
    ↓
在抽屉中查看既有方案，或基于当前通道点击“新增方案”
    ↓
进入新增运输方案页，确认来源通道与绑定主路径
    ↓
配置方案基础信息、标准服务组合、标准价格结构、标准时效、候选承运商
    ↓
保存草稿 或 启用方案
    ↓
后续报价引用运输方案内容生成正式报价
```

**关键决策点：**

- 通道本体状态和发布状态是两套并行状态，不可合并显示。
- 通道层发布到大厅前必须进入 `待审核`，不是点击后直接 `已发布`。
- 单一运输方式与多式联运共用同一套通道对象与路径建模方式，不单独新建对象。
- 通道层只维护参考价摘要；方案层才维护完整标准价格结构。

## 3. 核心概念与对象关系

### 3.1 核心对象

| 对象 | 说明 |
|---|---|
| 运输通道 | 企业内部运输能力资产，承载边界、路径、基础能力、展示摘要和发布状态 |
| 路径 | 运输通道下的可达走法集合，不单独维护独立状态 |
| 路段 | 路径中的具体运输段，承载起点、终点、运输方式 |
| 运输方案 | 基于来源通道和主路径沉淀的标准经营母版，用于后续报价引用 |
| 候选承运商 | 方案层按路段维护的候选资源池，不在通道层维护 |
| 报价 | 后续引用运输方案内容生成的正式商务结果，不在本 PRD 范围内展开 |

### 3.2 对象关系

- 一个运输通道下可维护多条路径。
- 一条路径下可维护多个连续路段。
- 一个运输方案必须绑定一个来源通道和该来源通道下的一条主路径。
- 同一条通道 / 路径可以衍生多个运输方案。
- 报价对运输方案是一次性引用，不与方案保持实时绑定。

### 3.3 状态流转

#### 3.3.1 运输通道本体状态

| 当前状态 | 触发动作 | 下一状态 | 说明 |
|---|---|---|---|
| 草稿 | 保存并启用 | 启用 | 需通过通道关键字段与路径闭合校验 |
| 启用 | 停用 | 停用 | 若当前已发布，发布状态需自动改为已下架 |
| 停用 | 本期不设计恢复链路 | - | 当前原型未展开恢复启用能力 |

#### 3.3.2 运输通道发布状态

| 当前状态 | 触发动作 | 下一状态 | 说明 |
|---|---|---|---|
| 未发布 | 点发布 | 待审核 | 仅启用态可发起 |
| 待审核 | 审核通过 | 已发布 | 审核后台口径，不在本期页面展开 |
| 待审核 | 审核驳回 | 已驳回 | 记录驳回原因 |
| 待审核 | 点撤回 | 未发布 | 撤回的是发布申请，不是停用通道 |
| 已发布 | 点下架 | 已下架 | 通道本体状态仍保持启用 |
| 已发布 | 编辑保存且大厅关键字段变更 | 已下架 | 需重新发起发布 |
| 已下架 | 点发布 | 待审核 | 重新进入审核链路 |
| 已驳回 | 编辑页点发布 | 待审核 | 不在列表直出“重新发布” |

#### 3.3.3 运输方案状态

| 当前状态 | 触发动作 | 下一状态 | 说明 |
|---|---|---|---|
| 草稿 | 启用方案 | 启用 | 需通过关键字段校验 |
| 启用 | 停用 | 停用 | 停用后不建议继续直接用于新报价 |
| 停用 | 复制新增 | 草稿 | 当前原型保留“复制新增”链路 |

## 4. 核心规则

1. **运输通道和运输方案必须严格分层**
   通道只负责边界、路径、能力和展示摘要；方案负责标准服务、标准价格、标准时效和候选承运商。

2. **通道本体状态和发布状态必须拆开维护**
   页面上必须分别展示，不允许合并成一个状态字段。

3. **发布不是直接上架，必须先进入待审核**
   通道点击 `发布` 后进入 `待审核`，审核通过后才进入 `已发布`。

4. **已驳回不在列表直接重发**
   列表只展示 1 行驳回原因摘要；完整驳回原因在编辑页查看，并由编辑页继续承接 `发布` 动作。

5. **已发布通道编辑大厅关键字段后必须自动下架**
   自动下架是保存后的联动结果，不是额外人工再点一次下架。

6. **计费条件全主题统一（术语修正）**
   通道层和方案层统一使用 **计费条件**（原 PRD 误用"计费依据"，按业务规则口径修正：计费条件 = 按什么算钱，计费依据 = 取装货/卸货哪个口径）。通道层和方案层的"按重量 / 按体积 / 按数量 / 按集装箱 / 按车 / 按里程"统一称为 **计费条件**；通道层和方案层如需表达散货装卸口径，使用 **计费依据**（按装货口径 / 按卸货口径）。

7. **按集装箱时，通道层与方案层职责不同**
   通道层仅维护统一参考价摘要；方案层必须维护箱型费用明细。

8. **来源通道停用后，不再新增方案，但既有方案保留**
   停用不反向删除方案；既有方案仍可查看，复制新增是否继续保留以后续规则为准。

## 5. 功能详细说明

### 5.1 运输通道管理页

#### 5.1.1 功能说明

- 功能目的：作为运输能力资产管理入口，承接查看、筛选、编辑、发布、停用通道，以及进入当前通道下的方案管理链路。
- 使用角色：经营维护人员、方案配置人员。
- 触发入口：进入运输通道管理菜单。
- 前置条件：无。

#### 5.1.2 页面与交互逻辑

- 页面先按通道本体状态 Tabs 和筛选区定位目标通道，再在列表执行动作。
- 管理列表必须同时展示：
  - 通道本体状态
  - 发布状态
  - 关联方案数
  - 关键展示摘要
- 管理列表不再展示解释性灰色副文案，如 `公路 + 铁路 + 水路 ｜ 出口`。
- `已驳回` 状态下，列表直接展示驳回原因 1 行摘要，不增加单独“查看驳回原因”按钮。
- 点击 `查看方案` 后，右侧打开真实的运输方案管理抽屉，而不是摘要弹窗。

#### 5.1.3 动作与状态口径

| 动作 | 展示条件 | 执行结果 | 备注 |
|---|---|---|---|
| 查看 | 全状态可见 | 进入查看页 | 当前原型用通道页只读态承接 |
| 编辑 | 全状态可见 | 进入编辑页 | 已驳回查看完整驳回原因也走编辑页 |
| 发布 | 草稿启用后、启用未发布、启用已下架时展示 | 发布状态改为待审核 | 已驳回统一进入编辑页后触发 |
| 撤回 | 仅待审核展示 | 发布状态改为未发布 | 仅撤回发布申请 |
| 下架 | 仅已发布展示 | 发布状态改为已下架 | 通道本体状态不变 |
| 停用 | 仅启用态展示 | 通道本体状态改为停用 | 若当前已发布，发布状态自动改为已下架 |
| 查看方案 | 启用 / 停用展示 | 打开方案管理抽屉 | 草稿态不展示 |

#### 5.1.4 校验规则

- 强校验：
  - 草稿和停用通道不可发起发布。
  - 停用态不可新增运输方案。
- 弱校验 / 提示：
  - 待审核中的通道仍可查看方案，但提示当前仍处于待审核状态。
- 二次确认：
  - 停用已发布通道时，需提示“停用后将自动下架，且不可继续新增方案”。

### 5.2 新增 / 编辑 / 查看运输通道页

#### 5.2.1 功能说明

- 功能目的：维护运输通道边界、路径结构、能力和展示摘要。
- 使用角色：经营维护人员。
- 触发入口：管理页点击新增 / 查看 / 编辑。
- 前置条件：无；单一运输方式与多式联运共用同一套页面和对象模型。

#### 5.2.2 页面与交互逻辑

- 页面结构固定为：
  - 基础信息区
  - 运输路线区
  - 服务能力区
  - 展示信息区
  - 底部操作区
- 运输方式选择为 `公路 / 水路 / 铁路` 时，页面进入单一运输方式验证态：
  - 默认 `1 条路径 + 1 个路段`
  - 路段运输方式自动统一为所选方式
- 运输方式选择为 `多式联运` 时，保留多段组合配置能力。
- 编辑页中，当发布状态为 `已驳回` 时，页面顶部固定展示完整驳回原因。
- 编辑已发布通道时，如果修改了大厅关键字段，保存后自动转 `已下架` 并提示需重新发布。

#### 5.2.3 校验规则

- 强校验：
  - 通道名称、运输方式、集货地、目的地为空时不可启用。
  - 每条路径首段起点必须等于集货地。
  - 每条路径末段终点必须等于目的地。
  - 相邻路段必须首尾衔接。
- 弱校验 / 提示：
  - 首段终点被改成中间点时，只提示继续补齐后续路段。
- 二次确认：
  - 从当前通道直接去新增方案前，如当前通道尚未保存，需先提示保存。

### 5.3 运输方案管理页（当前以右侧抽屉承接）

#### 5.3.1 功能说明

- 功能目的：查看当前通道下的既有方案、来源摘要、筛选条件和方案动作。
- 使用角色：方案配置人员、经营维护人员。
- 触发入口：运输通道管理页点击 `查看方案`。
- 前置条件：已有来源通道上下文。

#### 5.3.2 页面与交互逻辑

- 抽屉内固定包含四块内容：
  - 来源通道摘要区
  - 方案筛选区
  - 方案列表区
  - 当前通道相关轻提示
- 摘要区同步展示来源通道：
  - 通道名称
  - 集货点 → 目的地
  - 运输方式摘要
  - 路径数
  - 运输方案数（原"方案数"统一为"运输方案数"，避免与"通道方案"等历史别名混淆）
  - 通道本体状态 / 发布状态
- 来源通道为停用时：
  - 保留查看既有方案
  - 禁止新增方案
- 单一运输方式通道在无方案时，可给出轻提示，但不阻断抽屉查看。

#### 5.3.3 方案列表动作规则

| 动作 | 说明 | 当前口径 |
|---|---|---|
| 查看 | 查看当前方案摘要信息 | 当前原型以摘要查看 / Toast 占位承接 |
| 编辑 | 进入方案编辑链路 | 当前原型保留入口，正式页后续继续细化 |
| 复制新增 | 基于当前方案复制出新草稿 | 保留 |
| 停用 | 停用当前方案 | 方案停用不反向修改来源通道 |

#### 5.3.4 校验与边界

- 停用来源通道后：
  - 不再允许新增方案
  - 既有方案仍可查看
- 页面不展示正式报价金额、执行状态、货主侧信息。
- 候选承运商在列表中只展示配置摘要，不展开明细。

### 5.4 新增 / 编辑运输方案页

#### 5.4.1 功能说明

- 功能目的：基于来源通道与主路径沉淀标准经营母版。
- 使用角色：方案配置人员。
- 触发入口：方案抽屉点击 `新增方案`，或后续进入方案编辑页。
- 前置条件：必须带入来源通道上下文。

#### 5.4.2 页面与交互逻辑

- 页面结构固定为：
  - 来源信息与绑定路径
  - 方案基础信息
  - 标准服务组合
  - 标准价格结构
  - 标准时效
  - 路段候选承运商
  - 底部操作区
- 页面默认不提供“重新选择来源通道”控件；如需更换来源，返回上一层重新进入。
- 来源信息区需要明确展示：
  - 来源通道名称
  - 集货点 → 目的地
  - 运输方式
  - 通道编号（原"通道 ID"统一为业务编号表达）
  - 通道本体状态
  - 发布状态
  - 绑定主路径
  - 主路径结构
- 路径切换后，后续价格结构、候选承运商、分段结构均需按新路径重算。

#### 5.4.3 标准服务组合规则

- 方案层能力必须在来源通道能力范围内细化，不能超范围新增。
- `包含上门 / 包含末端 / 包含通关服务 / 包含增值服务 / 包含仓储中转` 作为主开关表达。
- 上门、末端范围采用省 / 市 / 区多选级联面板。
- 增值服务支持字典值多选和当前方案自定义新增。

#### 5.4.4 标准价格结构规则

- 费用组织方式统一为 `整段 / 分段`。
- **计费条件**（术语修正：原"计费依据"实际语义为按什么算钱，统一改为"计费条件"）统一为：
  - `按重量`
  - `按体积`
  - `按数量`
  - `按集装箱`
  - `按车`
  - `按里程`
- `按数量` 不再额外选择二级单位，按货品单位理解即可。
- `按集装箱` 时：
  - 通道层只展示统一参考价摘要
  - 方案层必须维护箱型费用明细
  - 集装箱场景固定为"按集装箱"，不区分装卸口径（即计费依据置空）
- 如需表达散杂货装卸口径，使用 **计费依据**（按装货口径 / 按卸货口径），与计费条件分开维护。
- 分段模式下必须覆盖当前主路径全部路段。
- 其他费用作为附加费用维护，不与主运价混为单字段。

#### 5.4.5 标准时效规则

- 时效类型支持：
  - 固定值
  - 区间值
  - 待确认
- 页面内实时展示预计时效预览，用于回写列表摘要。
- 当前原型不拆运输段 SLA，只验证方案级标准时效表达。

#### 5.4.6 候选承运商规则

- 候选承运商按路段配置，不允许只维护一个整单总列表。
- 页面主视图只展示已选结果和配置状态。
- 点击 `新增承运商` 后通过弹窗选择：
  - `自有合作`
  - `平台承运商`
- 选择器支持 Tab、关键字搜索、多选后统一回填。

#### 5.4.7 校验规则

- 强校验：
  - 未获取来源通道上下文，不可进入当前页保存。
  - 绑定主路径为空，不可保存。
  - 方案名称为空，不可保存。
  - 必填价格结构未完成时，不可启用方案。
  - 分段价格未覆盖全部路段时，不可启用方案。
- 弱校验 / 提示：
  - 来源通道停用后，只提示不建议继续用于新报价。
- 二次确认：
  - 切换主路径时，需提示价格结构、候选承运商等可能被重置。

## 6. 上下游联动

### 6.1 上游

- 无外部页面强制前置依赖；运输通道管理是当前主题主入口。
- 运输方案页的上游为来源通道与来源主路径。

### 6.2 下游

- 运输方案后续被正式报价页引用，作为标准母版。
- 正式报价引用后冻结，不与运输方案保持实时绑定。

### 6.3 页面间联动

- 通道保存成功后回写管理列表和统计摘要。
- 通道查看方案后打开当前通道的方案抽屉。
- 方案保存成功后回写当前通道方案数和抽屉列表。
- 已发布通道编辑大厅关键字段后自动下架，并回写列表状态。

## 7. 字段说明

### 7.1 运输通道管理页

- **通道名称**：类型：文本；展示条件：列表固定展示；联动影响：用于识别与检索。
- **集货点 → 目的地**：类型：文本；展示条件：列表固定展示；联动影响：表达通道边界。
- **运输方式摘要**：类型：标签 / 文本；展示条件：列表固定展示；展示口径：单一运输方式或多式联运摘要；联动影响：用于快速判断场景类型。
- **通道本体状态**：类型：状态标签；展示条件：列表固定展示；可选值：`草稿 / 启用 / 停用`；联动影响：控制通道动作。
- **发布状态**：类型：状态标签；展示条件：列表固定展示；可选值：`未发布 / 待审核 / 已发布 / 已下架 / 已驳回`；联动影响：控制发布相关动作；`已驳回` 时下方补 1 行驳回原因摘要。

### 7.2 新增 / 编辑运输通道页

- **通道名称**：类型：文本框；是否必填：是；展示条件：基础信息区默认显示；输入限制：上限 50 字，不允许纯空格；校验规则：为空不可启用；错误提示：`请输入通道名称`。
- **运输方式**：类型：下拉单选；是否必填：是；可选值：`公路 / 水路 / 铁路 / 多式联运`；联动影响：决定单一运输方式验证态或联运验证态。
- **集货地**：类型：地址录入；是否必填：是；联动影响：作为通道边界起点，首段起点默认带入。
- **目的地**：类型：地址录入；是否必填：是；联动影响：作为通道边界终点，末段终点默认带入。
- **路段运输方式**：类型：下拉单选；是否必填：是；可编辑条件：单一运输方式场景只读，多式联运可编辑；联动影响：生成路径摘要。
- **计费条件**：类型：下拉单选；是否必填：否；展示条件：参考价类型不为面议时显示；可选值：`按重量 / 按体积 / 按数量 / 按集装箱 / 按车 / 按里程`（术语修正：原字段名"计费依据"实际语义为"按什么算钱"，按业务规则统一改为"计费条件"）；联动影响：参与参考价摘要拼装；集装箱场景固定为"按集装箱"，不区分装卸口径（无计费依据）。
- **价格说明**：类型：文本框；是否必填：否；输入限制：上限 100 字；联动影响：补充通道参考价口径；按集装箱时用于表达“统一参考价，具体箱型以方案配置为准”等说明。

### 7.3 运输方案管理抽屉

- **来源通道摘要**：类型：只读摘要；展示条件：抽屉顶部固定展示；展示内容：通道名称 / 集货点→目的地 / 运输方式 / 路径数 / 方案数。
- **方案名称筛选**：类型：文本框；是否必填：否；输入限制：关键字搜索；联动影响：过滤方案列表。
- **绑定路径筛选**：类型：下拉单选；是否必填：否；默认值：`全部`；联动影响：按路径过滤方案列表。
- **方案状态筛选**：类型：下拉单选；是否必填：否；默认值：`全部`；可选值：`草稿 / 启用 / 停用`。
- **来源通道状态筛选**：类型：下拉单选；是否必填：否；默认值：`全部`；可选值：`启用 / 停用 / 草稿`。

### 7.4 新增 / 编辑运输方案页

- **来源通道标签**：类型：只读标签；展示条件：来源信息区固定展示；展示口径：通道编号（原"通道 ID"统一为业务编号表达） / 通道本体状态 / 发布状态。
- **绑定主路径**：类型：下拉单选；是否必填：是；默认值：带入当前通道主路径；校验规则：为空不可保存；错误提示：`请选择绑定主路径`。
- **主路径结构**：类型：路段列表；展示条件：已选择主路径时展示；展示内容：路段起终点 / 运输方式 / 业务类型。
- **方案名称**：类型：文本框；是否必填：是；输入限制：上限 50 字，不允许纯空格；错误提示：`请输入方案名称`。
- **费用组织方式**：类型：Pill 切换；是否必填：是；可选值：`整段 / 分段`；联动影响：切换后刷新价格结构表单。
- **计费条件**：类型：下拉单选；是否必填：是；可选值：`按重量 / 按体积 / 按数量 / 按集装箱 / 按车 / 按里程`（术语修正：原字段名"计费依据"统一为"计费条件"）；联动影响：决定价格结构展示方式；集装箱场景固定为"按集装箱"。
- **箱型费用明细**：类型：结构化列表；是否必填：是（按集装箱时）；展示条件：计费依据为 `按集装箱` 时显示；校验规则：至少维护 1 条有效箱型价格。
- **时效类型**：类型：Pill 切换；是否必填：是；可选值：`固定值 / 区间值 / 待确认`；联动影响：控制时效输入与预览。
- **新增承运商**：类型：按钮 + 弹窗；是否必填：否；展示条件：每个路段默认展示；联动影响：回填当前路段候选承运商。

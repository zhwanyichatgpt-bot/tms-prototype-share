# 询价大厅承运商端 PRD

> 说明：本文档只描述承运商端“询价大厅”的页面、字段、报价操作和结果查看。货主货源询价与无车承运人询价管理分别见对应子 PRD。

## 0. 一句话说明

承运商通过“询价大厅”查看当前自己可报价的路线级询价，并按单条路线提交报价；报价后该数据进入“我的报价记录”，在截止前且未被当前提交版本锁定时可继续修改报价，并用于查看成交或失效结果。

## 1. 背景与范围

### 1.1 需求背景
- 无车承运人将货源询价下的路线发布到询价大厅后，需要承运商按路线提交报价。
- 承运商不应看到整张货源询价的管理结构，只处理路线级询价发布单。
- 承运商需要在报价后追踪自己的报价状态和结果。

### 1.2 需求目标
- 支持承运商查看待报价路线池。
- 支持承运商按单条路线提交报价。
- 支持承运商查看自己的报价记录。
- 支持承运商识别报价是否未入围、已成交或已失效。

### 1.3 适用范围
- 承运商端“询价大厅”应用。
- 询价大厅列表页。
- 路线报价详情页。
- 我的报价记录页。

### 1.4 非本期范围
- 承运商对整张货源询价统一报价。
- 承运商查看货主整张货源询价全部路线。
- 承运商参与货主确认动作。
- 承运商履约调度流程。

### 1.5 原型状态
- 旧版原型已有询价大厅单路线报价 Tab。
- 后续原型需重构为承运商端“询价大厅列表页 / 路线报价详情页 / 我的报价记录页”。

## 2. 核心链路
1. 承运商进入“询价大厅”列表页。
2. 承运商筛选或查看可报价路线。
3. 承运商进入路线报价详情页。
4. 承运商查看路线信息、竞价截止时间和发布备注。
5. 承运商填写报价金额和报价备注。
6. 系统校验报价金额和竞价截止时间。
7. 承运商提交报价。
8. 报价回流至无车承运人端询价管理详情。
9. 承运商在“我的报价记录”中查看报价结果。

### 2.1 关键决策点
- 询价大厅展示路线级发布单，不展示货源询价主单。
- 询价大厅只展示当前承运商可报价的路线，不设置“全部”总池。
- 承运商一次只对一条路线报价。
- 同一承运商对同一路线原则上只保留一条有效报价。
- 已报价路线从大厅移入“我的报价记录”；若仍在报价期内且该报价未被当前提交版本锁定，则可在记录页继续修改。

## 3. 核心概念与对象关系

### 3.1 当前 PRD 管理对象
| 对象 | 说明 |
|---|---|
| 路线发布单 | 无车承运人发布到询价大厅的路线级报价入口 |
| 承运商报价 | 承运商针对单条路线提交的报价记录 |
| 我的报价记录 | 承运商查看自己历史报价和结果的列表 |

### 3.2 对象关系
- 1 张路线发布单可被多个承运商报价。
- 1 个承运商对同一路线原则上只保留 1 条有效报价。
- 1 条路线发布单对同一承运商而言，同一时刻只会落在“询价大厅”或“我的报价记录”其中一个视图池中。
- 1 条承运商报价可进入已报价、未入围、已成交、已失效等结果。

### 3.3 状态流转
#### 承运商视角报价状态
待报价 → 已报价 → 未入围 / 已成交 / 已失效

## 4. 核心规则
1. 承运商只能对路线级发布单报价。
2. 承运商不得对整张货源询价统一报价。
3. 报价金额必填且必须大于 0。
4. 超过竞价截止时间不可报价。
5. 已取消、已失效或超时失效路线不可报价。
6. 同一承运商对同一路线原则上只保留一条有效报价。
7. 询价大厅只展示当前承运商当前可报价的路线发布单。
8. 承运商一旦提交报价，该路线应从询价大厅移出，进入“我的报价记录”。
9. 承运商端不直接展示“待货主确认、已确认、已生成托运单”等内部路线处理状态。
10. 无车承运人内部选中某家承运商作为当前提交版本基准报价时，承运商侧报价状态仍保持“已报价”，不新增“已入围”状态。
11. 已报价且未截止、且未被当前提交版本锁定时，承运商可在“我的报价记录”中修改报价，系统仅保留最新有效报价。
12. 若报价已被当前提交版本锁定，则在货主确认前不可修改；若后续未被继续采用且仍在报价期内，可恢复修改。

## 5. 功能详细说明

### 5.1 询价大厅列表页
#### 5.1.1 功能说明
- 功能目的：支持承运商查看待报价路线池。
- 使用角色：承运商。
- 触发入口：承运商端菜单“询价大厅”。
- 前置条件：无车承运人已将路线发布到询价大厅。

#### 5.1.2 页面与交互逻辑
- 页面标题直接为“询价大厅”，不设置“全部”总池页签。
- 默认只展示当前承运商当前可报价的路线级发布单。
- 支持按始发地、目的地、货品、运输方式、询价类型、截止时间筛选。
- 列表中的路线统一处于“待报价”视角，仅支持进入报价详情页执行报价。
- 当前承运商一旦完成报价，该路线立即从询价大厅移出，不再留在大厅列表中；如后续需修改报价，在“我的报价记录”中完成。
- “待货主确认、已确认、已生成托运单”等内部路线状态不在承运商端大厅直接展示。
- 是否仍在继续收报价、上游是否已提交货主等内部处理判断，不在承运商端大厅和详情页额外外显说明。

#### 5.1.3 列表字段
| 字段 | 说明 |
|---|---|
| 路线发布单号 | 路线发布至询价大厅后生成的单号 |
| 询价类型 | 长协货源询价 / 零星货源询价 |
| 始发地 | 路线起点 |
| 目的地 | 路线终点 |
| 货品 | 货物名称 |
| 配载方式 | 按重量、按数量、按体积 |
| 货量 | 路线规模数值 |
| 单位 | 与配载方式联动的计量单位 |
| 运输方式 | 汽运 / 水运 / 铁路等 |
| 竞价截止时间 | 可报价截止时间 |
| 距截止时间 | 用于辅助判断报价紧急程度 |
| 大厅状态 | 固定展示为“待报价”，表示当前承运商仍可参与报价 |
| 操作 | 报价 |

### 5.2 路线报价详情页
#### 5.2.1 功能说明
- 功能目的：支持承运商查看单条路线信息并提交报价。
- 使用角色：承运商。
- 触发入口：询价大厅列表页“报价 / 查看”。
- 前置条件：路线发布单有效且未超过竞价截止时间。

#### 5.2.2 页面与交互逻辑
- 路线信息区展示始发地、目的地、货品、配载方式、货量、单位、运输方式、路线备注。
- 竞价信息区展示竞价截止时间、发布备注、当前承运商视角状态。
- 报价信息区按报价方式只填写一个主报价金额：按运输单价报价时填写运输单价并自动折算运输总价；按运输总价报价时填写运输总价并自动折算运输单价，折算结果只读展示在输入框旁。
- 提交报价后系统生成报价时间，并将报价同步给无车承运人。
- 提交报价成功后，该路线从询价大厅移出并进入“我的报价记录”。
- 若从“我的报价记录”进入修改报价，沿用同一报价详情页，只更新当前承运商该路线的最新有效报价，不新增第二条有效记录。
- 超过竞价截止时间后，报价按钮不可用。

#### 5.2.3 校验规则
- 强校验：报价金额为空不可提交。
- 强校验：报价金额必须大于 0。
- 强校验：超过竞价截止时间不可提交。
- 强校验：路线已取消或已失效不可提交。
- 强校验：若当前报价已被上游提交版本锁定，则不可修改。
- 弱校验：报价备注为空不拦截。

#### 5.2.4 路线信息字段
- 路线发布单号：类型：只读文本；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：系统生成；校验规则：无；联动影响：作为报价关联单号。
- 询价类型：类型：只读文本；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货源询价；校验规则：无；联动影响：用于承运商识别业务类型。
- 始发地：类型：只读文本；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货主路线；校验规则：无；联动影响：作为报价基础信息。
- 目的地：类型：只读文本；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货主路线；校验规则：无；联动影响：作为报价基础信息。
- 货品：类型：只读文本；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货主路线；校验规则：无；联动影响：作为报价基础信息。
- 配载方式：类型：只读文本；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货主路线；校验规则：无；联动影响：作为报价参考基础。
- 货量：类型：只读数字；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货主路线；校验规则：无；联动影响：作为报价参考基础。
- 单位：类型：只读文本；是否必填：是；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货主路线；校验规则：无；联动影响：与货量共同展示路线规模。
- 运输方式：类型：只读文本；是否必填：否；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自货主路线；校验规则：无；联动影响：作为报价参考基础。
- 发布备注：类型：只读文本；是否必填：否；展示条件：详情页展示；可编辑条件：不可编辑；默认值：来自无车承运人发布信息；校验规则：无；联动影响：作为报价补充参考。

#### 5.2.5 报价字段
- 报价方式：类型：单选；是否必填：是；展示条件：报价详情页展示；可编辑条件：未截止且路线有效时可编辑；默认值：按运输单价；可选值：按运输单价、按运输总价；校验规则：为空不可提交；错误提示："请选择报价方式"；联动影响：决定主报价金额输入与折算方向。
- 报价金额（主）：类型：数字输入框；是否必填：是；展示条件：报价详情页展示；可编辑条件：未截止且路线有效时可编辑；默认值：空；输入限制：仅支持正数；整数最多9位；小数最多2位；校验规则：为空或小于等于0不可提交；错误提示："请填写正确的报价金额"；联动影响：作为无车承运人选价依据。
- 折算金额（只读）：类型：计算展示；是否必填：否；展示条件：填写主报价金额后自动折算并展示在输入框旁；可编辑条件：否；折算规则：按运输单价时折算运输总价 = 运输单价 × 路线货量；按运输总价时折算运输单价 = 运输总价 ÷ 路线货量；折算基数固定为路线发布单的货量；展示格式：整数千分位 + 2位小数 + 单位后缀（元）；校验规则：货量为0或缺失时不折算并提示。
- 报价备注：类型：文本域；是否必填：否；展示条件：报价详情页展示；可编辑条件：未截止且路线有效时可编辑；默认值：空；输入限制：上限300字符；校验规则：无；联动影响：作为报价补充说明。
- 报价时间：类型：系统时间；是否必填：是；展示条件：提交成功后展示；可编辑条件：不可编辑；默认值：系统生成；校验规则：无；联动影响：作为报价记录时间。
- 报价状态：类型：状态字段；是否必填：是；展示条件：列表与详情展示；可编辑条件：系统控制；默认值：提交前为待报价，提交后为已报价；选项内容/来源：待报价、已报价、未入围、已成交、已失效；校验规则：无；联动影响：影响承运商可执行动作。

### 5.3 我的报价记录页
#### 5.3.1 功能说明
- 功能目的：支持承运商查看自己提交过的报价及后续结果。
- 使用角色：承运商。
- 触发入口：承运商端菜单“我的报价记录”或询价大厅内页签。
- 前置条件：承运商已提交过报价。

#### 5.3.2 页面与交互逻辑
- 默认展示当前承运商的报价记录。
- 支持按报价状态、路线、货品、报价时间筛选。
- 支持查看报价详情。
- 询价大厅中已完成报价的路线，必须在本页面承接，不再继续留在询价大厅。
- 被无车承运人选为当前提交版本基准报价、但货主尚未最终确认前，报价状态仍展示为“已报价”。
- 已报价且未截止、且未被当前提交版本锁定时，支持修改报价；被当前提交版本锁定后不展示修改入口。

#### 5.3.3 列表字段
| 字段 | 说明 |
|---|---|
| 报价单号 | 承运商报价记录编号 |
| 路线发布单号 | 对应路线发布单 |
| 询价类型 | 长协货源询价 / 零星货源询价 |
| 始发地 | 路线起点 |
| 目的地 | 路线终点 |
| 货品 | 货物名称 |
| 配载方式 | 按重量、按数量、按体积 |
| 货量 | 路线规模数值 |
| 单位 | 与配载方式联动的计量单位 |
| 报价金额 | 承运商提交金额 |
| 报价状态 | 已报价、未入围、已成交、已失效 |
| 报价时间 | 提交报价时间 |
| 操作 | 查看、修改报价 |

## 6. 上下游联动
### 6.1 上游
- 路线发布单来自无车承运人端“询价管理”。

### 6.2 下游
- 承运商报价提交后同步回无车承运人端“询价管理”详情页。
- 报价入围、未入围、成交、失效结果由无车承运人选价和货主确认流程触发。
- 无车承运人和货主侧的内部路线处理状态，不直接作为承运商端大厅状态透出。

### 6.3 关联模块
- 询价管理。
- 货源询价。
- 指定托运单管理。

## 7. 字段说明

### 7.1 字段组织口径
- 各页面字段已在第5章按"列表页字段 / 详情页字段 / 报价字段"区块完整展开，字段类型、必填、默认值、校验规则、联动影响均以第5章为准，本节不再重复。
- 跨页面共用的路线信息字段（始发地、目的地、货品、配载方式、货量、单位、运输方式、路线发布单号、询价类型）口径完全一致，来源均为货主路线或货源询价发布数据。

### 7.2 状态枚举集中说明
- 大厅状态：仅"待报价"（承运商视角，已报价路线不入大厅）。
- 报价状态（全集）：待报价、已报价、未入围、已成交、已失效。
- 全局路线处理状态（货主/无车承运人侧使用，承运商端不透出）以[[08-方案设计/货源询价_广林项目定制总览_PRD_v1]]为准。

### 7.3 报价方式枚举
- 按运输单价：承运商填写运输单价，系统按"运输单价 × 路线货量"折算运输总价。
- 按运输总价：承运商填写运输总价，系统按"运输总价 ÷ 路线货量"折算运输单价。
- 折算基数固定为路线发布单的货量，货量为0或缺失时不折算并提示。

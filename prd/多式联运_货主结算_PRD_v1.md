# 多式联运货主结算 PRD

## 0. 一句话说明

多式联运货主结算用于结算人员在运输结算模块中新增货主结算单，按结算方选择可结算联运计划，系统根据联运计划客户侧费用规则带出未结算量、计费依据、费用明细和结算金额，并生成面向货主的统一结算单；分段结算支持各子计划（路段）异构计费（不同路段不同计费条件/计费依据/单价/单位）。

## 1. 背景与范围

### 1.1 需求背景

- 多式联运已具备联运计划创建、路线编排和客户侧费用规则配置能力，但尚未形成运输结算模块中的货主应收结算闭环。
- 联运计划可能持续数周或数月，货主结算不能强依赖整张联运计划完成后才发起。
- 结算人员需要在运输结算模块中按结算方新增结算单，选择该结算方下可结算的联运计划，并由系统按结算规则自动核算金额。
- MVP 重点是跑通“联运计划 -> 货主结算单”的应收结算链路，不展开一单制凭证费用展示和承运商应付清算。
- 2026-06-03 原型验证已确认：详情页以“基础信息 + 全单费用汇总 + 左侧联运计划汇总 + 右侧计费详情”展示已生成结算单结果，计费详情按计费类型、基础运费、补贴费用、扣减费用和核算结果分组。
- 2026-07-04 异构分段原型验证已确认：分段结算采用「子计划（路段）在上、货品/箱型明细在下」结构，各子计划独立计费条件/计费依据/单价/单位（异构分段，如公水公「吨+箱+吨」混排）；结算量、已结算量、未结算量按子计划级独立维护；运输单价可按本次结算调整（快照、不反改合同）；补贴扣减挂在货品/箱型明细行级。

### 1.2 需求目标

- 支持结算人员新增多式联运货主结算单。
- 支持一张结算单选择同一结算方下的多个联运计划。
- 支持按联运计划自动带出运输总量、已结算量、未结算量和本次结算量。
- 支持整票结算和分段结算两种客户侧主运费计算方式。
- 分段结算支持各子计划（路段）异构计费：不同路段可配置不同计费条件、计费依据、单价和单位（如公水公「按吨装货 + 按箱 + 按吨卸货」）。
- 分段结算下结算量、已结算量、未结算量按子计划级独立维护。
- 支持本次结算量默认等于未结算量，可减少、不可增加。
- 支持补贴金额、扣减金额和核算运费合计；补贴扣减按货品/箱型明细行级维护。
- 支持运输单价按本次结算调整，调整仅对本次结算单生效（快照），不反改联运计划费用规则。
- 支持提交后将参与统计的内部运单按子计划（路段）级精确标记到运单维度，避免重复结算并支持后续追溯。
- 支持货主结算详情页查看结算单基础信息、全单费用汇总、联运计划汇总和单计划计费详情。
- 支持整票 + 多货品、分段 + 多货品、整票 + 多箱型、分段 + 多箱型四类展示场景。

### 1.3 适用范围

- 适用模块：运输结算、多式联运。
- 适用页面：新增运输结算单中的多式联运货主结算场景、货主结算单详情页。
- 适用角色：结算人员、财务人员。
- 适用对象：结算方、联运计划、内部运单、货主结算单。

### 1.4 非本期范围

- 不做草稿状态。
- 不做一单制运输凭证费用展示。
- 不做承运商应付结算。
- 不按子计划拆成多张结算单，一张结算单内按子计划分组核算。
- 不支持结算页修改联运计划费用规则（运输单价可按本次结算调整，但不反改联运计划费用规则）。
- 不做税率、含税、不含税和税额计算。
- 不支持多币种、分润、代垫等复杂清分。
- 不在货主结算详情页展示 OA 流程、OA 单号或查看 OA 流程按钮。
- 不在货主结算详情页展示查看依据、运单选择或内部运单占用明细。

## 2. 核心链路

```text
结算人员进入运输结算模块
    ↓
点击新增结算单
    ↓
选择结算对象和结算方
    ↓
点击添加联运计划
    ↓
系统展示当前结算方下可结算联运计划
    ↓
结算人员选择一个或多个联运计划
    ↓
系统带出联运计划信息、计费规则、未结算量和费用试算
    ↓
结算人员确认或调减本次结算量
    ↓
按需添加补贴金额或扣减金额
    ↓
系统计算结算总额
    ↓
提交结算单
    ↓
结算单进入待审核，并标记相关联运计划与内部运单的已结算占用
    ↓
详情页查看基础信息、全单费用汇总、联运计划汇总和计费详情
```

关键决策点：

- 新增结算单支持选择多个联运计划，但所有联运计划必须属于同一结算方。
- 整票结算和分段结算都是货主侧主运费计算方式，不决定货主结算单数量。
- 分段结算采用「子计划（路段）在上、货品/箱型明细在下」结构，各子计划独立计费条件/计费依据/单价/单位，支持异构分段（如公水公「吨+箱+吨」混排）。
- 分段结算下结算量、已结算量、未结算量按子计划级独立维护；各子计划按自身计费依据取自身装卸确认量。
- 联运计划是否可结算，不取决于联运计划是否已完成，而取决于是否存在未结算量。
- 运输单价可按本次结算调整，调整仅对本次结算单生效（快照），不反改联运计划费用规则。
- 提交后不进入草稿，直接进入待审核。
- 待审核到待打款由外部 OA 或既有流程结果驱动，页面不提供应用内审核通过 / 驳回操作。

## 3. 核心概念与对象关系

### 3.1 核心对象

| 对象 | 说明 |
|---|---|
| 结算对象 | 运输结算模块中的结算业务类型或对象分类，当前页面用于货主结算。 |
| 结算方 | 本次对客结算的货主 / 托运企业 / 合同结算主体。 |
| 联运计划 | 多式联运客户侧应收结算的来源主单。 |
| 子计划 | 联运计划下按运输路段拆分的执行计划；分段结算下作为独立计费单元，承载该路段的计费条件、计费依据、单价和单价单位。 |
| 内部运单 | 联运计划下实际运输执行记录，用于形成装货、卸货、箱型箱数等结算依据数据。 |
| 货主结算单 | 面向结算方生成的正式应收结算单。 |
| 本次结算量 | 本次结算单对某个联运计划（整票）或某个子计划（分段）确认的结算数量、重量、体积或箱数。 |
| 运输总量 | 整票：按计费依据口径统计的已确认可结算总量，装货口径取首段装货确认量，卸货口径取末段卸货确认量。分段：各子计划按自身计费依据取自身装卸确认量汇总。 |
| 已结算量 | 已进入有效结算单且未作废的累计结算量；整票按联运计划级统计，分段按子计划级独立统计。 |
| 未结算量 | 运输总量减已结算量后的剩余可结算量；整票按联运计划级，分段按子计划级。 |
| 补贴金额 | 沿用既有结算页面命名，用于表达本次结算中的增项费用；按货品/箱型明细行级维护。 |
| 扣减金额 | 沿用既有结算页面命名，用于表达本次结算中的减项费用；按货品/箱型明细行级维护。 |

### 3.2 对象关系

- 一张货主结算单对应一个结算方。
- 一张货主结算单可包含多个联运计划。
- 一个联运计划在不同时间可进入多张货主结算单，但同一结算量不可重复结算。
- 一个联运计划下的内部运单用于提供结算依据数据，并在提交结算后按子计划（路段）级精确标记到运单维度。
- 分段结算下，结算量、已结算量、未结算量按子计划（路段）级独立维护；同一联运计划下不同子计划的量纲可不同（如公路段按吨、水路段按箱）。
- 分段结算下，各子计划拥有独立的计费条件、计费依据、单价和单价单位，支持异构分段（如公水公「按吨装货 + 按箱 + 按吨卸货」）。

### 3.3 状态流转

| 当前状态 | 触发动作 | 下一状态 | 说明 |
|---|---|---|---|
| 新建未提交 | 提交 | 待审核 | 提交成功后生成正式结算单并占用本次结算量。 |
| 待审核 | 外部审核完成 / OA 结果同步 | 待打款 | 进入付款或收款处理阶段，页面不提供应用内审核按钮。 |
| 待审核 | 外部 OA 驳回 / 退回 | 已作废 | OA 驳回视为本次结算无效，结算单置为已作废并释放本次结算量占用；如需结算须重新发起一张结算单（本期不做"驳回退回新建编辑"路径，避免占用状态歧义）。 |
| 待审核 | 作废 | 已作废 | 作废后释放本次结算量占用。 |
| 待打款 | 打款完成 | 已打款 | 结算完成。 |
| 待打款 | 作废 | 已作废 | 待打款作废沿用现有结算模块权限控制。 |
| 已打款 | 查看 | 已打款 | 已打款状态不允许修改核心结算内容。 |
| 已作废 | 查看 | 已作废 | 已作废状态不参与有效已结算量统计。 |

## 4. 核心规则

1. 货主结算始终挂在主联运计划上，不按子计划拆成多张货主结算单；分段结算在一张结算单内按子计划分组核算。
2. 一张结算单支持选择同一结算方下的多个联运计划。
3. 整票结算和分段结算都是货主主运费的计算方式。
4. 整票结算：散货 / 普货按计划级统一计费条件、计费依据、运输单价计算；集装箱按箱型维护运输单价，不同箱型可不同单价。
5. 分段结算：各子计划（路段）独立计费条件、计费依据、单价、单价单位，支持异构分段；散货 / 普货按子计划（路段）级统一单价，集装箱按该子计划下的箱型维护单价。
6. 分段结算下，结算量、已结算量、未结算量按子计划（路段）级独立维护；同一联运计划下不同子计划的量纲可不同。
7. 计费依据决定结算量取值来源：整票装货口径取首段装货确认量、卸货口径取末段卸货确认量；分段各子计划按自身计费依据取自身装卸确认量；集装箱子计划计费依据置空。
8. 未结算量 = 运输总量（或子计划确认总量） − 已结算量。
9. 本次结算量默认等于未结算量，可减少、不可增加。
10. 主运费金额由系统按结算规则自动计算。
11. 金额差异可通过调整本次结算单价或补贴/扣减处理；散货 / 普货按计划级或子计划（路段）级调整，集装箱按箱型调整；调整单价仅对本次结算单生效（快照），不反改联运计划费用规则，调整记录留痕支持审计追溯。
12. 提交后占用本次结算量（整票按联运计划级、分段按子计划级），避免重复结算。
13. 提交后如发现错误，走作废、重建或后续差异调整，不直接编辑正式结算结果。
14. 内部运单按子计划（路段）级 + 量纲分别精确标记参与结算的数量占用、结算单号和结算批次。
15. 多货品按货品拆结算明细行，多箱型按箱型拆结算明细行，不合并为不可追溯的单行费用；散货 / 普货货品行不单独维护运输单价，集装箱箱型行维护箱型单价。
16. 补贴金额、扣减金额按货品/箱型明细行级维护，每个货品/箱型各自维护自己的补贴扣减。
17. 详情页只读展示已生成结算结果，不允许修改本次结算量、运输单价、补贴金额或扣减金额。

## 5. 功能详细说明

### 5.1 基础信息

#### 5.1.1 功能说明

- 功能目的：维护本次货主结算单的基础结算主体和结算日期信息。
- 使用角色：结算人员。
- 触发入口：运输结算模块点击新增结算单。

#### 5.1.2 页面与交互逻辑

- 页面沿用既有新增运输结算单结构，不新增大幅差异化布局。
- 结算对象、结算方、结算日期、结算总额、备注沿用现有基础信息区表达。
- 结算方选定后，系统按结算方筛选可添加的联运计划。
- 已添加联运计划后，如修改结算方，需清空已选联运计划及费用明细。
- 结算总额由系统根据已选联运计划、补贴金额和扣减金额自动计算，只读展示。

#### 5.1.3 字段规则

| 字段 | 规则 |
|---|---|
| 结算对象 | 必填，沿用既有结算页面字段。 |
| 结算方 | 必填，用于筛选可结算联运计划。 |
| 结算日期 | 必填，默认当前日期，可修改。 |
| 结算总额 | 只读，由系统计算。 |
| 备注 | 选填，可修改。 |

### 5.2 添加联运计划

#### 5.2.1 功能说明

- 功能目的：选择当前结算方下满足结算条件的联运计划，作为本次货主结算单的核算对象。
- 使用角色：结算人员。
- 前置条件：已选择结算方。

#### 5.2.2 页面与交互逻辑

- 按钮名称建议为“添加联运计划”，位置沿用原“添加核算运单”区域。
- 点击后打开选择弹窗或抽屉，展示当前结算方下可结算联运计划。
- 支持多选联运计划。
- 联运计划选择后回填到“核算联运计划”区域，按联运计划分组展示。
- 已选联运计划可移除，移除后同步重算结算总额。
- 选择列表需展示联运计划号、路线或货品摘要、运输方式、托运企业 / 结算方、运输总量、待结算总量、运输单价或计价方式、状态。
- 多货品场景下，待结算总量按货品拆分摘要展示；多箱型场景下，按箱型拆分摘要展示。

#### 5.2.3 可选规则

联运计划可被选择需同时满足：

- 结算方与当前选择结算方一致。
- 联运计划已生效，且未作废、未失效。
- 联运计划存在客户侧费用规则。
- 未结算量大于 0。
- 关键结算依据数据已形成。
- 未被异常、争议或冻结状态锁定。
- 本次可结算量未被其他有效结算单占用。

不可选时需展示不可选原因，例如：

- 未结算量为 0。
- 缺少客户侧费用规则。
- 缺少首段装货确认量。
- 缺少末段卸货确认量。
- 联运计划已作废。
- 存在结算争议锁定。

### 5.3 核算联运计划

#### 5.3.1 功能说明

- 功能目的：展示已选联运计划的结算规则、结算量、费用试算和核算结果。
- 使用角色：结算人员。

#### 5.3.2 页面与交互逻辑

- 沿用既有页面“任务单号分组”形态，改为“联运计划号分组”。
- 分组标题展示联运计划号、联运计划名称和结算方式标签。
- 分组右侧展示计费条件、计费依据和主运费公式。
- 表格主体按货品 / 箱型拆行展示运输总量、已结算量、未结算量、本次结算量、基础运费、扣减金额、补贴金额和核算运费。
- 分段结算时，在联运计划分组内提供“分段价格构成”展开信息。
- 合计行沿用现有页面合计形式。

#### 5.3.3 字段规则

| 字段 | 规则 |
|---|---|
| 联运计划编号 / 名称 | 只读，来源于联运计划。 |
| 结算方式 | 只读，来源于联运计划费用规则，取值为整票结算 / 分段结算。 |
| 计费条件 | 只读，来源于联运计划费用规则。 |
| 计费依据 | 只读，来源于联运计划费用规则。 |
| 单价 / 路段单价 | 新增页可按本次结算调整，详情页只读展示；原联运计划费用规则不被反改。 |
| 运输总量 | 只读，由系统按计费依据统计。 |
| 已结算量 | 只读，按有效结算单统计，不含已作废结算单。 |
| 未结算量 | 只读，等于运输总量减已结算量。 |
| 本次结算量 | 新增页默认等于未结算量，可减少，不可增加，必须大于 0；详情页只读展示。 |
| 基础运费 | 只读，由系统按结算规则计算。 |
| 扣减金额 | 可添加、修改、删除，沿用既有页面命名。 |
| 补贴金额 | 可添加、修改、删除，沿用既有页面命名。 |
| 核算运费 | 只读，等于基础运费 + 补贴金额 - 扣减金额。 |

### 5.4 整票结算

#### 5.4.1 功能说明

- 功能目的：按联运计划统一计费规则计算货主主运费；散货 / 普货使用计划级统一运输单价，集装箱使用箱型级运输单价。
- 适用场景：客户侧费用规则为整票结算。

#### 5.4.2 计算规则

```text
散货 / 普货本次基础运费 = Σ(各货品行本次结算量 × 计划级运输单价)
集装箱本次基础运费 = Σ(各箱型本次结算量 × 该箱型运输单价)
```

#### 5.4.3 展示规则

- 整票结算按货品 / 箱型拆结算明细行。
- 基础运费表展示货品 / 箱型、全程路线、运输总量、已结算量、未结算量、本次结算量、运输单价和基础运费。
- 散货 / 普货多货品行展示同一个计划级运输单价，单价调整入口在计划级，不在货品行级分别调整。
- 补贴费用、扣减费用不混入基础运费表，在详情页计费详情中独立分组展示。
- 集装箱整票结算按箱型拆行，例如 20GP、40GP、40HQ；不同箱型的运输总量、已结算量、未结算量、本次结算量、运输单价和基础运费分别展示。

#### 5.4.4 多货品 / 多箱型本次结算量维护颗粒度

- 整票结算下，本次结算量按货品行 / 箱型行独立维护：每行默认等于该行的未结算量，可单独调减、不可增加；不要求各行本次结算量等比例。
- 本次结算量不允许跨行挪用：A 货品行未结算量大于 0 时，不能用 B 货品行的剩余可结算量补足 A。
- 整票散货 / 普货基础运费 = Σ(各货品行本次结算量 × 计划级统一运输单价)，货品名称不同不自动产生不同单价。
- 整票集装箱基础运费 = Σ(各箱型本次结算量 × 该箱型运输单价)，不同箱型可不同单价。

按装货口径：

```text
运输总量 = 首段累计装货确认量
未结算量 = 运输总量 - 已结算量
```

按卸货口径：

```text
运输总量 = 末段累计卸货确认量
未结算量 = 运输总量 - 已结算量
```

本次结算量：

```text
0 < 本次结算量 <= 未结算量
```

### 5.5 分段结算（异构分段）

#### 5.5.1 功能说明

- 功能目的：各子计划（路段）按各自的计费条件、计费依据、单价、单价单位独立计费，最后汇总形成货主主运费。
- 适用场景：客户侧费用规则为分段结算。
- 异构分段：不同路段可采用不同计费方式，如公水公联运中「公路按重量装货口径 + 水路按集装箱 + 公路按重量卸货口径」。

#### 5.5.2 业务定义

分段结算采用「子计划（路段）在上、货品/箱型明细在下」结构：

- 各子计划独立配置计费条件（按重量/按体积/按数量/按集装箱）、计费依据（装货口径/卸货口径，集装箱段置空）、单价、单价单位。
- 分段散货 / 普货按子计划（路段）级统一运输单价；同一子计划内不同货品行只拆分结算量、补贴、扣减和追溯，不分别维护运输单价。
- 分段集装箱按子计划（路段）+ 箱型维护运输单价；同一子计划内不同箱型可不同单价。
- 各子计划按自身计费依据取自身装卸确认量，形成该段的确认总量。
- 集装箱子计划计费依据置空时，确认总量按该段箱型箱数汇总取值（即各箱型箱数 × 单箱标准箱量的累计值，按业务实际口径统计），不区分装卸口径。
- 各子计划独立维护已结算量、未结算量、本次结算量；同一联运计划下不同子计划的量纲可不同（如公路段按吨、水路段按箱）。
- 本次结算量默认等于该段未结算量，可减少、不可增加。
- 子计划是否可结算，取决于该子计划是否存在未结算量，不取决于该子计划是否已完成。

#### 5.5.3 计算规则

```text
散货 / 普货路段金额 = Σ(该段各货品行本次结算量 × 该段统一单价)
集装箱路段金额 = Σ(该段各箱型本次结算量 × 该箱型单价)
结算总额 = Σ(各路段金额) + 补贴合计 − 扣减合计
```

集装箱路段按箱型明细汇总：该段金额 = Σ(各箱型本次结算量 × 该箱型单价)。散货 / 普货路段按货品拆行展示，但同一路段内各货品共用该路段单价。

示例（公水公异构分段）：

| 子计划 | 运输方式 | 计费条件 | 计费依据 | 单价 | 本次结算量 | 路段金额 |
|---|---|---|---|---:|---:|---:|
| 子计划1 | 公路 | 按重量 | 装货口径 | 80 元/吨 | 300 吨 | 24000 元 |
| 子计划2 | 水路 | 按集装箱 | （置空） | 4500 元/箱 | 15 箱 | 67500 元 |
| 子计划3 | 公路 | 按重量 | 卸货口径 | 60 元/吨 | 295 吨 | 17700 元 |
| 合计 | - | - | - | - | - | 109200 元 |

#### 5.5.4 展示规则

- 分段结算采用「子计划（路段）在上、货品/箱型明细在下」的分组结构。
- 每个子计划信息（子计划号、运输方式、装卸点、计费条件、计费依据、单价）作为表外信息条，展示在该段明细表上方，不混入表格内容。
- 每个子计划下的明细表与整票结算同款列结构：货品/箱型、运输总量、已结算量、未结算量、本次结算量、运输单价、基础运费、补贴金额、扣减金额、核算运费。
- 各子计划下明细按该段计费条件拆行：按重量/体积/数量 → 按货品行；按集装箱 → 按箱型行（如 20GP、40GP、40HQ）。
- 不同子计划的明细量纲可不同（公路段行显示吨、水路段行显示箱），单价单位相应不同；散货 / 普货同一子计划内各货品行展示同一路段单价，集装箱同一子计划内各箱型行展示各自箱型单价。
- 每个子计划明细表底部为该子计划小计行；整个联运计划底部为合计行。

### 5.6 补贴金额与扣减金额

#### 5.6.1 功能说明

- 功能目的：沿用既有结算页面中的补贴金额和扣减金额能力，处理本次结算中的增项和减项。

#### 5.6.2 页面与交互逻辑

- 补贴金额、扣减金额按货品/箱型明细行级维护：整票结算下每个货品/箱型各自维护；分段结算下各子计划的每个货品/箱型明细行各自维护。
- 每个货品/箱型明细行的补贴、扣减均可点击打开维护弹窗，不存在「空白不可维护」的单元格。
- MVP 保留批量添加补贴项、批量添加扣减项入口位置，但暂不启用批量能力，补贴 / 扣减在明细行内维护。
- 补贴金额和扣减金额需纳入结算总额。
- 补贴和扣减不反改联运计划费用规则。
- 分段结算下，补贴扣减需记录归属子计划、货品/箱型、费用项目和金额。
- 详情页中补贴费用和扣减费用需独立分组展示，不依赖弹窗作为唯一入口。
- 整票结算下补贴/扣减明细不展示路段信息；分段结算下展示所属子计划。
- 无补贴或无扣减时，使用轻量空态文案，不使用大面积插画空态。

### 5.7 多货品与集装箱展示

#### 5.7.1 功能说明

- 功能目的：支持一个联运计划下存在多个货品或多个集装箱箱型时，结算量和费用可按业务对象拆分追溯。

#### 5.7.2 展示规则

- 多货品场景按货品拆结算明细行。
- 集装箱场景按箱型拆结算明细行，例如 20GP、40GP、40HQ。
- 不同货品 / 箱型的运输总量、已结算量、未结算量、本次结算量、运输单价、基础运费、补贴金额、扣减金额和核算运费分别展示；散货 / 普货货品行展示计划级或路段级单价，集装箱箱型行展示箱型单价。
- 分段结算下，各子计划内按该段计费条件拆行（按吨段→货品行、按箱段→箱型行）；同一货品/箱型在不同子计划下各自独立展示。
- 不允许把多个货品 / 箱型合并为一条不可追溯的费用行。

### 5.8 内部运单结算标记

#### 5.8.1 功能说明

- 功能目的：提交结算单后，将本次结算量对应的内部运单精确标记到运单维度，支持防重复结算和后续追溯。

#### 5.8.2 标记规则

提交结算单后，系统按子计划（路段）级 + 量纲分别精确标记占用。整票结算按联运计划级统一量标记；分段结算各子计划按自身量纲（吨/箱等）独立标记。

整票结算下若存在多货品/多箱型，本次结算量按货品/箱型明细行级分别标记占用：每行内部运单按其所属货品/箱型 + 依据数据形成顺序占用，直到占满该行本次结算量。不同货品/箱型行的占用量各自独立、互不挪用，与 5.4.4 的本次结算量维护颗粒度一致。

每个占用记录需包含：

- 结算单号。
- 结算方。
- 联运计划号。
- 子计划号（分段结算必填）。
- 内部运单号。
- 该子计划计费条件。
- 该子计划计费依据。
- 本次结算量（按该子计划量纲）。
- 本次结算占用量。
- 结算前累计已结算量。
- 结算后累计已结算量。
- 对应装货确认 / 卸货确认 / 箱型箱数来源。
- 标记时间。

如果本次结算量小于未结算量，系统应按该子计划内部运单的依据数据形成顺序进行数量占用，直到占满本次结算量。不同子计划的占用量纲可能不同（吨 vs 箱），各自独立记录、独立防重。

示例（分段结算下某公路子计划按吨占用）：

| 内部运单 | 可结算量 | 本次占用量 | 说明 |
|---|---:|---:|---|
| 运单A | 100 吨 | 100 吨 | 全量占用 |
| 运单B | 150 吨 | 150 吨 | 全量占用 |
| 运单C | 200 吨 | 50 吨 | 部分占用 |

### 5.9 货主结算单详情页

#### 5.9.1 功能说明

- 功能目的：展示已生成多式联运货主结算单的基础信息、全单费用汇总、联运计划汇总和当前选中联运计划的计费详情。
- 使用角色：结算人员、财务人员。
- 页面性质：只读详情页，不允许修改数量、单价、补贴、扣减或结算结果。

#### 5.9.2 页面结构

详情页采用以下结构：

```text
货主结算单详情
├─ 基础信息
├─ 全单费用汇总
└─ 主内容区
   ├─ 左侧：联运计划汇总
   └─ 右侧：计费详情
      ├─ 计费类型
      ├─ 基础运费
      ├─ 补贴费用
      ├─ 扣减费用
      └─ 核算结果
```

#### 5.9.3 基础信息字段

详情页基础信息保留：

- 结算单号。
- 状态。
- 结算对象。
- 结算方。
- 结算日期。
- 结算总额。
- 创建人。
- 创建时间。
- 备注。

详情页不展示：

- OA 流程。
- OA 单号。
- 查看 OA 流程按钮。

#### 5.9.4 全单费用汇总

全单费用汇总展示：

- 基础运费合计。
- 补贴金额合计。
- 扣减金额合计。
- 结算总额。

计算关系：

```text
结算总额 = 基础运费合计 + 补贴金额合计 - 扣减金额合计
```

#### 5.9.5 左侧联运计划汇总

左侧按联运计划卡片展示：

- 联运计划号。
- 结算方式标签：整票结算 / 分段结算。
- 联运计划名称或路线摘要。
- 计费条件和计费依据。
- 货品 / 箱型摘要。
- 基础运费。
- 补贴金额。
- 扣减金额。
- 核算运费。

交互规则：

- 点击左侧联运计划，右侧切换展示该联运计划计费详情。
- 左侧联运计划汇总和右侧计费详情为同级面板，顶部需水平对齐。

#### 5.9.6 右侧计费详情

右侧不展示“计算详情”总标题，直接从“计费类型”分组开始。

计费类型分组展示：

- 联运计划号。
- 结算方式。
- 整票结算：计费条件、计费依据、计价方式、计费单位（计划级统一）。
- 分段结算：计价方式为「Σ(各段本次结算量 × 各段单价)」，并标注「各子计划独立计费条件/依据/单价，详见下方各路段」。

基础运费分组展示：

- 整票结算：按货品 / 箱型展示基础运费表，字段为货品 / 箱型、全程路线、运输总量、已结算量、未结算量、本次结算量、运输单价、基础运费。
- 分段结算：按子计划（路段）分组展示，每个子计划信息条（子计划号、运输方式、装卸点、计费条件、计费依据、单价）位于该段明细表上方；明细表字段为货品/箱型、确认总量、已结算量、未结算量、本次结算量、运输单价、明细金额、补贴金额、扣减金额、核算运费。
- 分段各子计划下明细按该段计费条件拆行（按吨段→货品、按箱段→箱型），不同子计划量纲可不同。
- 每个子计划底部展示该段小计行。

补贴费用分组展示：

- 字段为货品 / 箱型、所属子计划、补贴项目、补贴金额。
- 整票结算按货品/箱型展开。
- 分段结算按子计划 × 货品/箱型明细行展开，展示归属子计划。

扣减费用分组展示：

- 字段为货品 / 箱型、所属子计划、扣减项目、扣减金额。
- 整票结算按货品/箱型展开。
- 分段结算按子计划 × 货品/箱型明细行展开，展示归属子计划。

核算结果分组展示：

- 基础运费合计。
- 补贴金额合计。
- 扣减金额合计。
- 核算运费。

计算关系：

```text
核算运费 = 基础运费合计 + 补贴金额合计 - 扣减金额合计
```

#### 5.9.8 UI 表达规则

- 左侧联运计划汇总和右侧计费详情需水平对齐，避免详情面板视觉上突出一块。
- 右侧分组标题统一使用左侧蓝色竖线和加粗标题。

```text
新增运输结算单

│  ├─ 批量添加补贴项（MVP 暂不启用）
│  ├─ 批量添加扣减项（MVP 暂不启用）
│  └─ 核算说明：结算总额 = Σ各段明细金额 + 补贴合计 − 扣减合计
├─ 联运计划分组
│  ├─ 整票：计划号 / 结算方式标签 / 计费条件 / 计费依据 / 主运费公式 / 结算量与费用表 / 合计行
│  └─ 分段：计划号 / 结算方式标签
│     └─ 按子计划（路段）分组
│        ├─ 子计划信息条（表外）：子计划号 / 运输方式 / 装卸点 / 计费条件 / 计费依据 / 单价
│        ├─ 该段明细表（与整票同款列）：货品/箱型 / 运输总量 / 已结算量 / 未结算量 / 本次结算量 / 运输单价 / 基础运费 / 补贴金额 / 扣减金额 / 核算运费
│        └─ 子计划小计行
│     └─ 计划合计行
└─ 页面动作
   ├─ 返回
   └─ 提交
```

### 6.2 详情页结构

详情页沿用既有运输结算详情的“上方基础信息 + 下方左右详情”结构。

```text
结算单详情
├─ 基础信息
│  ├─ 结算单号
│  ├─ 状态
│  ├─ 结算对象
│  ├─ 结算方
│  ├─ 结算日期
│  ├─ 结算总额
│  ├─ 创建人
│  ├─ 创建时间
│  └─ 备注
├─ 全单费用汇总
│  ├─ 基础运费合计
│  ├─ 补贴金额合计
│  ├─ 扣减金额合计
│  └─ 结算总额
└─ 主内容区
   ├─ 联运计划汇总
   └─ 计费详情
      ├─ 计费类型
      ├─ 基础运费
      ├─ 补贴费用
      ├─ 扣减费用
      └─ 核算结果
```

详情页不展示 OA 流程、OA 单号、查看依据、运单选择和内部运单占用明细。

## 7. 字段编辑规则

### 7.1 不可修改字段

- 联运计划编号 / 名称。
- 运输路线。
- 货品摘要。
- 结算方式。
- 计费条件。
- 计费依据。
- 散货 / 普货货品行运输单价（来源于计划级或子计划级单价，不按货品行独立维护）。
- 运输总量 / 子计划确认总量。
- 已结算量。
- 未结算量。
- 基础运费公式。
- 基础运费金额（由系统按结算量×单价自动计算）。

### 7.2 可修改字段

新增页可修改：

- 结算日期。
- 备注。
- 本次结算量，可减少、不可增加（整票按联运计划级、分段按子计划级各自的明细行）。
- 运输单价 / 路段单价：散货 / 普货整票按计划级调整，分段按子计划（路段）级调整；集装箱按箱型调整。调整仅对本次结算单生效（快照），不反改联运计划费用规则；调整记录留痕支持审计追溯。
- 补贴金额、扣减金额：按货品/箱型明细行级维护，每个货品/箱型各自可增删改。
- 已选联运计划，可移除。

详情页全部核心结算字段只读，不允许修改数量、单价、补贴、扣减和结算结果。

### 7.3 有条件修改字段

- 结算方：已选联运计划后修改结算方，需先清空已选联运计划及费用明细。

## 8. 提交校验

提交时需校验：

- 结算对象已选择。
- 结算方已选择。
- 至少已添加一个联运计划。
- 整票：每个联运计划本次结算量大于 0、不大于未结算量。
- 分段：各子计划各明细行本次结算量不大于该行未结算量、不为负。
- 已选联运计划仍处于可结算状态。
- 联运计划费用规则完整（整票为计划级、分段为各子计划级）。
- 运输单价合法（大于 0；散货 / 普货校验计划级或子计划级单价，集装箱校验各箱型单价）。
- 基础运费计算成功。
- 补贴金额和扣减金额格式合法。
- 同一内部运单同一数量范围未被其他有效结算单重复占用（整票按联运计划级、分段按子计划级 + 量纲）。

## 9. 上下游联动

### 9.1 上游

- 联运计划提供结算方、路线、货品、箱型、结算方式、计费条件、计费依据、计划级单价、路段级单价和箱型单价。
- 内部运单提供装货确认、卸货确认、箱型箱数等结算依据数据。
- 既有运输结算模块提供结算对象、状态流转和页面基础结构。

### 9.2 下游

- 提交后生成货主结算单。
- 货主结算单进入待审核状态。
- 外部审核完成或 OA 结果同步后进入待打款。
- 打款完成后进入已打款。
- 作废后进入已作废，并释放本次结算量占用。

### 9.3 边界说明

- 结算页不反向修改联运计划费用规则（运输单价可按本次结算调整并快照，但不反改联运计划费用规则原文；散货 / 普货不按货品行反向生成差异单价）。
- 已打款结算单不允许修改核心结算内容。
- 已作废结算单不参与历史有效已结算量统计（整票按联运计划级、分段按子计划级释放占用）。
- 内部运单标记用于货主结算追溯，不替代承运商应付结算。
- 详情页不承载应用内审核操作，审核流由外部 OA 或既有流程处理。

## 11. 字段枚举集中说明

> 本章集中沉淀货主结算 PRD 中跨章节复用的字段枚举，方便检索与对齐。各字段详细规则仍以第 5 章 / 第 7 章为准。

### 11.1 计费条件（来自 [[计费条件与计费依据口径]]）

| 取值 | 适用 | 说明 |
|---|---|---|
| 按重量 | 整票 / 分段（散货段） | 计费依据可选装货口径 / 卸货口径 |
| 按体积 | 整票 / 分段（散货段） | 计费依据可选装货口径 / 卸货口径 |
| 按数量 | 整票 / 分段（散货段） | 计费依据可选装货口径 / 卸货口径 |
| 按集装箱 | 整票 / 分段（集装箱段） | 计费依据置空 |
| 按车 | 暂未纳入本期 MVP | 预留 |
| 按里程 | 暂未纳入本期 MVP | 预留 |

### 11.2 计费依据（仅散杂货段使用）

| 取值 | 整票取值 | 分段取值 |
|---|---|---|
| 按装货口径 | 首段累计装货确认量 | 该子计划装货确认量 |
| 按卸货口径 | 末段累计卸货确认量 | 该子计划卸货确认量 |
| 置空 | 集装箱场景 | 集装箱子计划段 |

### 11.3 结算方式

| 取值 | 计费单元 | 量纲维护 |
|---|---|---|
| 整票结算 | 联运计划级统一 | 联运计划级 |
| 分段结算 | 子计划（路段）级 | 子计划级独立 |

### 11.4 运输单价层级

| 业务类型 | 整票结算单价层级 | 分段结算单价层级 |
|---|---|---|
| 散货 / 普货 | 联运计划级统一单价；不同货品行共用该单价 | 子计划（路段）级统一单价；同一路段不同货品行共用该路段单价 |
| 集装箱 | 箱型级单价；不同箱型可不同单价 | 子计划（路段）+ 箱型级单价；同一路段不同箱型可不同单价 |

### 11.5 货主结算单状态

| 状态 | 触发条件 | 是否参与有效已结算量统计 |
|---|---|---|
| 待审核 | 新建提交 | 是（占用） |
| 待打款 | 外部 OA 审核通过 | 是 |
| 已打款 | 打款完成 | 是 |
| 已作废 | 用户作废 / OA 驳回 | 否（释放占用） |

### 11.6 费用项类型

| 取值 | 含义 | 维护层级 |
|---|---|---|
| 补贴金额 | 增项费用 | 货品 / 箱型明细行级 |
| 扣减金额 | 减项费用 | 货品 / 箱型明细行级 |

## 12. 附录与待确认事项

### 12.1 待确认事项

- 散货 / 普货按货品差异化单价不纳入当前 MVP；如后续真实合同要求按货种差异计价，应作为合同价目表增强能力单独设计。
- 节点级单独收费、港杂站杂拆分、混合计价等增强能力暂未纳入本期 MVP，待业务诉求明确后再补。
- 多币种、分润、代垫等复杂清分场景未纳入本期。
- 税率、含税 / 不含税 / 税额计算未纳入本期。
- 整票结算下"按车""按里程"计费条件预留，待业务确认后开放。
- 详情页内部运单占用明细的展示形态（本期不展示），待后续追溯能力上线后单独定义。
